## 1. 范围

### 1.1 本轮实现

- Vue 3 + Vite + TypeScript + Pinia + Vue Router
- Element Plus + ECharts
- B · 深蓝 + 琥珀主题；顶部导航；头像在右
- 登录 / 注册 / 管理员建校 / 组织 / 教师 / 课程 / 任务 / 题库 / 训练 / 报告页面
- 角色路由守卫、权限裁剪、403 / 404 / 空态 / 加载态
- 三路录制、WebSocket、回放、雷达图、排行榜、CSV 下载交互
- 桌面端 1024—1920；Chrome / Edge

### 1.2 不做

- 移动端 / 平板适配
- 多语言（本轮中文）
- 暗 / 亮主题切换（固定深色 B 主题）
- 服务端渲染、PWA、离线
- 富文本编辑器、语音点评、视频剪辑
- 可视化低代码搭建
- 浏览器兼容 Safari / Firefox（录制 / 回放只保证 Chrome / Edge）

### 3.1 AppShell

```text
┌ 64px 顶部导航 ──────────────────────────────────────────────┐
│ Logo  课程  任务  训练  题库资源 / 管理菜单       [头像 ▾]  │
├─────────────────────────────────────────────────────────────┤
│ 面包屑 / 页面标题                                            │
│                                                             │
│ 内容区 max-width 1440，左右 32px                             │
└─────────────────────────────────────────────────────────────┘
```

- 顶部导航固定 64 px；背景 `#0B1220` / 半透明毛玻璃；底部 1 px 边框。
- 左侧 Logo + 产品名；主导航按角色裁剪；右侧头像 / 账号菜单。
- 内容区默认最大 1440 px，表单页 1280 px；1920 屏居中留白。
- 页面滚动在内容区；顶部导航固定。
- 移动端不做；最小宽度 1024 px。

### 3.2 角色导航

| 角色 | 主导航 |
|---|---|
| 学生 | 课程、任务、训练、我的成绩 |
| 教师 | 课程、题库资源、训练模板 |
| 管理员 | 学校与组织、教师管理、课程管理 |

- 导航项通过 `meta.nav` 声明，不硬编码在模板。
- 当前路由高亮琥珀色下划线 / 文字。
- 学生导航不出现题库、评分、统计、导出。
- 管理员导航不出现任务、训练、报告。
- 教师导航不出现管理员组织维护。

### 3.3 账号抽屉

- 右侧头像点击打开 320 px 抽屉。
- 展示：姓名、用户名、账号类型、学校、专业 / 班级（学生）、教师专业。
- 只读；本轮不做修改资料 / 改密码。
- 「账号与安全」入口：绑定 / 解绑邮箱、微信；解绑最后一个登录方式时前端先禁用并提示。
- 底部「退出登录」；清除 token，跳 `/login`。
- 账号类型标签：学生 / 教师 / 管理员。

#### 3.3.1 登录方式与 OAuth 引导

- `/login` 三个 tab：用户名密码 / 邮箱验证码 / 微信扫码；保留注册入口与“忘记密码暂不支持”说明。
- 邮箱 tab：输入邮箱 → 发送验证码（60 秒倒计时）→ 输入 6 位码 → 登录；错误统一“邮箱或验证码不正确”，429 提示稍后重试。
- 微信 tab：展示二维码与过期倒计时；轮询 `status`，支持 `pending/scanned/authorized/needs_registration/expired`；过期可刷新。
- 微信未绑定：跳 `/register/oauth?ticket=...`，选择账号类型并补齐学校 / 专业 / 班级 / 用户名；提交后自动登录。
- JWT 只在 exchange / register 的响应体返回，不写入 URL、localStorage 或日志；沿用 `sessionStorage` token 策略。
- `/settings/security`：展示邮箱、微信绑定状态；绑定 / 换绑需验证码或重新扫码；解绑需当前密码；最后一个登录方式禁止解绑。
- 公开页仍走 AuthLayout；OAuth 引导注册复用两步注册的选项查询与校验组件。

### 3.4 管理员外壳

- 管理员使用同一 AppShell，但导航为管理项。
- 未绑定学校的管理员只显示 `/admin/setup`，不显示其他导航。
- 管理员不展示任务、报告、训练入口。

### 3.5 沉浸式布局

- 课堂 / 面试 / 回放使用 `ImmersiveLayout`：
  - 顶部 56 px：返回、任务名、状态、录制指示、退出；
  - 隐藏主导航，避免误触；
  - 退出前确认；录制中退出提示会结束本次。
- 回放页可显示完整事件流侧栏；课堂页显示虚拟学生 / 题目。
- 全屏时只保留播放控件 / 结束按钮。

### 4.2 路由 meta

```ts
meta: {
  requiresAuth: true,
  roles: ['teacher'],
  permission: 'task:create',
  layout: 'app',
  title: '新建任务',
  nav: 'courses'
}
```

- `requiresAuth`：无 token → `/login?redirect=...`。
- `roles`：账号类型不匹配 → `/403`。
- `permission`：前端权限码仅用于隐藏 / 提前提示；最终以服务端 403 为准。
- `layout`：`auth` / `app` / `immersive`。
- `title`：浏览器标题 + 面包屑。

### 4.3 守卫顺序

1. 读取 token；无 → 登录页。
2. 获取 / 恢复 `me`；失败 → 清除 token、登录页。
3. 未绑定管理员 → `/admin/setup`。
4. 账号类型与路由 `roles` 校验。
5. 权限码校验（可选）。
6. 账号类型默认首页：学生 `/student`、教师 `/teacher`、管理员 `/admin`（重定向 `/admin/org`）。
7. 已登录访问 `/login` / `/register` → 首页。

- 路由守卫不是安全边界；服务端仍需 URL + 资源级校验。
- 403 页面提供返回首页；不泄露资源是否存在。

### 4.4 页面状态

| 状态 | 组件 |
|---|---|
| 加载 | 骨架屏 / 局部 loading |
| 空 | `EmptyState`：图标 + 说明 + 主操作 |
| 错误 | `ErrorState`：错误码 + 重试 + 返回 |
| 403 | 无权限说明 + 返回 |
| 404 | 未找到 + 返回 |
| 网络断开 | 顶部条 + 重试 |
| 版本冲突 | 对话框：刷新 / 保留本地 |

### 5.4 Element Plus 深色定制

- 根节点 `html.dark`；覆盖 `--el-bg-color`、`--el-bg-color-overlay`、`--el-border-color`、`--el-text-color-*`、`--el-color-primary`。
- `--el-color-primary: #F5A524`；`--el-color-primary-light-3` 等派生色手动指定。
- 表格、输入、抽屉、对话框、下拉、日期选择统一深色。
- 主按钮文字使用 `--primary-ink`，避免琥珀底白字对比不足。
- 弹窗遮罩 `rgba(3, 8, 18, 0.72)`。

### 5.5 动效

- 150—200 ms ease-out；抽屉 220 ms；页面切换 120 ms 淡入。
- 录制红点 1.5 s 呼吸；倒计时仅颜色变化，不做闪烁。
- 尊重 `prefers-reduced-motion`：关闭非必要动画。

## 6. 页面模板

### 6.1 列表页

```text
┌ 页面标题 / 说明                         [主操作] ┐
│ 筛选栏：搜索 / 下拉 / 状态 / 日期               │
├─────────────────────────────────────────────────┤
│ 表格 / 卡片                                      │
│ 分页                                             │
└─────────────────────────────────────────────────┘
```

- 标题 24 px；说明 14 px 次色；主操作右对齐。
- 筛选栏一行；超过 4 个筛选收进「更多筛选」。
- 表格支持排序、分页、空态；默认 `size=20`。
- 行操作不超过 3 个，更多放「⋯」菜单。
- 卡片列表用于学生课程 / 任务 / 训练模板；表格用于教师 / 管理员。

### 6.2 详情页

```text
┌ 返回 / 标题 / 状态 / 操作 ───────────────────────┐
│ 摘要卡：关键指标 / 元信息                         │
├─────────────────────────────────────────────────┤
│ Tab：概览 / 名单 / 统计 / 设置                    │
└─────────────────────────────────────────────────┘
```

- 标题 + 状态 badge + 操作按钮。
- 摘要卡 2—4 个；桌面一行。
- Tab 切换不刷新页面；URL query 保留 tab。
- 只读信息用定义列表，不用禁用输入框伪装。

### 6.3 表单页（布局 B）

```text
┌ 返回 / 标题 ──────────────────────────────────────┐
│ ┌ 左：表单 720 ─────────────┐ ┌ 右：摘要 320 ───┐ │
│ │ 分节 1 / 2 / 3 / 4         │ │ 关键值 / 校验   │ │
│ │                            │ │ [保存] [发布]   │ │
│ └────────────────────────────┘ └─────────────────┘ │
└───────────────────────────────────────────────────┘
```

- 用于创建 / 编辑任务。
- 右侧摘要 `sticky`，顶部与表单对齐；底部操作固定。
- 分节标题 + 说明；字段 1—2 列；长文本全宽。
- 保存状态：保存中 / 已保存 HH:mm / 失败。
- 离开有未保存变更时确认。

### 6.4 抽屉表单

- 宽 480 / 640 / 960 px（评分 / 题目 / 选题）。
- 标题 + 关闭；底部固定操作。
- 抽屉内滚动；不遮挡顶部导航。
- 关闭有未保存变更时确认。

### 6.5 沉浸式课堂 / 面试

- 顶部 56 px 状态条；内容区填满视口。
- 课堂：共享窗口主画面 + 虚拟学生侧栏 + 摄像头小窗 + 底部控制条。
- 面试：摄像头主画面 + 题干侧栏 + 总倒计时 + 底部设备状态。
- 退出 / 结束二次确认；录制中不提供普通返回。
- 不使用全局 toast 遮挡题干；错误用顶部条 / 侧栏提示。

### 6.6 报告页

- 左侧分数卡 + 雷达；右侧维度卡 + 建议 + 问题时间线。
- 总分大号数字；AI / 教师 / 最终在 M7 学生页分三张卡。
- 建议点击跳转回放；回放页接受 `?t={ms}`。
- 打印不做；导出由 M7 CSV / 报告后续扩展。

## 8. 状态管理与数据

### 8.1 Pinia stores

| Store | 内容 | 持久化 |
|---|---|---|
| `auth` | token、`me`、permissions、账号类型 | `sessionStorage` token；`me` 内存 |
| `ui` | 全局 loading、toast、抽屉、主题 | 无 |
| `taskDraft` | 当前任务草稿、脏标记、自动保存 | 内存 + 本地草稿 |
| `interview` | session、当前题、剩余时间、录制状态 | 内存 |
| `training` | 当前训练 session / 记录 | 内存 |

- 服务端列表 / 详情用页面级 composable 缓存；不全部塞 Pinia。
- 切换账号 / 退出清空所有 store。
- 不把答案要点、参考材料、权重写入 `localStorage`。

### 8.2 API client

```ts
type ApiError = {
  code: string;
  message: string;
  details?: Record<string, unknown>;
  trace_id?: string;
};
```

- Base URL `/api/v1`；`Authorization: Bearer <token>`。
- 统一处理：
  - 401：清 token，跳登录，保留 `redirect`；
  - 403：跳 `/403` 或局部提示；
  - 409：版本冲突 / 重复，交页面处理；
  - 422：字段错误映射到表单；
  - 429：提示稍后重试；
  - 503：AI / 服务不可用提示；
  - 网络错误：顶部条 + 重试。
- 请求取消：页面切换 / 搜索防抖使用 `AbortController`。
- 上传：`XMLHttpRequest` 或 fetch + FormData，显示进度。
- 下载：CSV 用 `Blob` + `Content-Disposition` 文件名；显示失败原因。

### 8.3 轮询与实时

- 评测报告 `pending / running`：5 s / 3 s 轮询；终态停止；页面隐藏时暂停。
- 任务 / 统计列表：进入页面拉取；操作后局部刷新。
- 任务评分名单、统计页、学生成绩页存在 `pending_ai` 行时 3—5 s 轮询；AI 完成后最终分自动出现；终态停止。
- 课堂 / 面试：WebSocket 事件驱动；HTTP 只做初始快照 / 兜底。
- 训练记录：选中后轮询评测状态；终态停止。

## 9. 表单与校验

- Element Plus `Form` + `rules`；客户端规则与 02 / 模块设计一致。
- 分数输入：0—100，一位小数；失焦格式化；越界即时提示。
- 权重：滑杆 + 数字联动；合计不为 100 时保存 / 发布禁用。
- 富文本不做；评语 / 题干用 `textarea` + 字数计数。
- 文件上传：格式 / 大小前端预校验；解析状态轮询 / 返回；失败可重试。
- 自动保存：
  - 任务草稿 2 s 防抖；
  - 显示保存状态；
  - 发布前强制保存；
  - 离开未保存确认。
- 服务端 422 字段错误定位到控件；顶层错误用 banner。
- 双击提交防护：按钮 loading + 幂等键（如适用）。

## 10. 录制、WebSocket 与回放

### 10.1 设备检查

- 摄像头预览 16:9；麦克风电平条；网络状态。
- 课堂模式额外选择共享窗口（`getDisplayMedia`），只共享选定窗口。
- 权限拒绝 / 设备缺失 / 不支持 → 明确原因 + 重试。
- 浏览器检查：仅 Chrome / Edge；不支持的浏览器显示阻断页。

### 10.2 录制

- 三路 MediaRecorder：camera / screen / audio；5 s timeslice。
- 5 MB part 上传；三路并行；显示每路状态 / 进度。
- `RecordingStatus` 固定在课堂底部；失败 / 断流立即提示。
- 结束：`fix-webm-duration` + 最后 part + complete；显示上传进度。
- 录制中禁止页面刷新 / 关闭提示；不做断点续传。

### 10.3 WebSocket

- 连接前 `POST /sessions/{id}/ws-ticket`；ticket 一次性。
- 控制 WS 与感知 WS 分开；感知 WS 只传音频。
- 连接后处理 `session.snapshot`（含 `last_seq`）；事件按 `seq` 去重 / 排序。
- 控制 WS 断开：显示 30 秒 grace 倒计时，重新申请 ticket 并发送 `session.resume {last_seq, recording_state}`；重连成功后补放缺失事件。
- 页面刷新 / 录制器丢失 / 30 秒超时：失败页，不尝试恢复。
- 心跳 / 时钟同步；事件 reducer 更新课堂 / 面试状态；UI 不自行推断服务端状态。
- `WsStatus` 顶部条：连接中 / 已连接 / 重连中（剩余 N 秒）/ 断开失败。

### 10.4 回放

- 只支持 Chrome / Edge WebM。
- 音频主时钟；三路同步；500 ms 检查漂移 > 200 ms 校正。
- 事件点击 seek；`?t={ms}` 初始定位。
- 预签名 URL 15 分钟；过期重新获取。
- 全屏：屏幕主画面 + 摄像头小窗；面试摄像头主画面。
- 播放 / 暂停 / 倍速 / 音量 / 全屏；键盘空格 / 左右箭头可选。

## 13. 响应式、可访问性与性能

### 13.1 响应式

- 桌面优先：1280 标准，1440 最大内容宽，1920 居中。
- 最小支持 1024；小于 1024 显示「请使用桌面浏览器」提示，不强行适配。
- 表格在 1024—1280 横向滚动；筛选栏换行。
- 不做移动端课堂 / 面试。

### 13.2 可访问性

- 所有交互可键盘访问；可见 focus ring（琥珀 2 px）。
- 按钮 / 图标有 `aria-label`；图标不单独承载语义。
- 状态不只靠颜色：badge 文字 + 图标。
- 对比度：正文 ≥ 4.5:1；大字 ≥ 3:1。
- 面试 / 课堂倒计时使用 `aria-live="polite"`，避免频繁打断。
- 尊重 `prefers-reduced-motion`。
- 表单错误与控件 `aria-describedby` 关联。

### 13.3 性能

- 路由懒加载；ECharts、录制、回放、题目选择器按需加载。
- 首屏 JS 目标 < 300 KB gzip（不含图表 / 录制 chunk）。
- 图片 / 头像懒加载；虚拟学生 30 人以内不做虚拟滚动。
- 搜索 300 ms 防抖；请求取消。
- 列表分页；不做一次性拉取全部提交件。
- 录制期间避免大对象存 Pinia；MediaRecorder buffer 只在录制模块内。
- 报告页图表延后到数据到达后初始化；销毁时 `dispose`。

## 14. 安全与隐私

- token 存 `sessionStorage`，刷新保留、关闭标签页清除；不使用 `localStorage` 长期保存。
- 不在前端持久化答案要点、参考材料、权重、其他学生数据。
- 学生端接口响应裁剪由服务端负责；前端不请求无权资源。
- 路由守卫只做体验；服务端 403 为最终边界。
- 用户输入渲染使用 Vue 插值 / 文本，不使用 `v-html`；富文本本轮不做。
- 文件上传限制类型 / 大小；文件名不直接拼路径。
- 回放 / 报告 URL 使用预签名短时效；过期刷新。
- 错误提示不泄露堆栈、SQL、内部 URL。
- 退出登录清空 store / sessionStorage / 进行中的 WS / 录制。
