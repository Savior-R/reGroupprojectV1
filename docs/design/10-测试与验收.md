## 1. 目标与范围

### 1.1 目标

- 证明 M1—M7 的 P0 功能形成端到端闭环
- 证明权限、数据隔离、保留期与隐私边界不可绕过
- 证明 3 个虚拟课堂并发、评测 90 秒内完成等演示目标
- 证明失败、重试、部分成功、断线等异常路径可恢复 / 可解释
- 形成可重复执行的自动化测试与人工验收脚本

### 1.2 范围

- 单元、集成、契约、端到端、性能、安全、兼容性、可访问性、迁移与清理
- Java 业务、Python AI / worker、Vue 前端、Nginx / Docker Compose
- 演示种子数据与独立 M7 演示模式

### 1.3 不在本轮

- 生产级压测（100+ 课堂、跨地域）
- Safari / Firefox 录制回放
- 移动端
- 第三方云服务真实 SLA 验证（使用可替换适配层 + mock）
- AI 评测质量的学术级效度评估；只验证结构、边界、可复现与 mock 行为
- 灾备 / 多活

## 2. 测试分层与工具

| 层级 | 范围 | 工具 | 频率 |
|---|---|---|---|
| 单元 | Java 领域服务 / 校验 / 计算；Python 评分 / 解析；Vue 组件 | JUnit 5 + Mockito + AssertJ；pytest；Vitest | 每次提交 |
| 集成 | Spring Boot + PostgreSQL / Redis / MinIO；Python worker；API | Testcontainers；pytest + httpx；WireMock | 每次提交 / CI |
| 契约 | REST DTO、错误码、回调、WS 信封 | JSON Schema / 手写 fixture；WebSocket test client | CI |
| 端到端 | 浏览器主流程 | Playwright（Chromium） | nightly / 发布前 |
| 性能 | 3 课堂、3 评测、上传、回放 | k6 / Gatling；自定义 WS 压测 | 发布前 |
| 安全 | 认证、越权、上传、注入 | JUnit / pytest + OWASP ZAP baseline | 发布前 |
| 兼容性 | Chrome / Edge、1280 / 1440 / 1920 | Playwright projects | 发布前 |
| 可访问性 | 关键页面 | axe-core + 人工键盘检查 | 发布前 |
| 迁移 / 清理 | Flyway、保留期、级联 | Testcontainers + 定时任务测试 | CI / 发布前 |

- 后端使用 Gradle；Python 使用 pytest；前端使用 npm / pnpm（按仓库实际）。
- CI 不使用 H2 替代 PostgreSQL：JSONB、部分唯一索引、`FOR UPDATE` 需要真实 PostgreSQL。
- MinIO / Redis 使用 Testcontainers 或 Docker Compose 测试服务。
- 时间相关逻辑注入 `Clock`，测试不 `sleep`；WS / 队列用可控调度器。

## 3. 测试环境与配置

| 环境 | 用途 | 数据 |
|---|---|---|
| Local | 开发自测 | Docker Compose；demo seed |
| CI | 单元 / 集成 / 契约 | 临时 Testcontainers；每个测试独立 schema / 事务 |
| Staging / Demo | E2E、性能、验收 | 固定演示数据；可重置 |
| Production | 只做冒烟 / 监控 | 不使用测试数据 |

- `test` profile：关闭真实 AI 调用，使用 mock adapter；关闭真实邮件 / 外部 OCR。
- `demo` profile：加载 `V900__demo_seed.sql` + MinIO 样例录像；不调用真实评测 worker 也能演示 M7。
- `staging` profile：可切换真实 DeepSeek / OCR / ASR，配置独立密钥与限额。
- 每个测试使用唯一学校 / 账号前缀；测试结束清理；避免共享可变种子。

## 4. 测试数据与种子

### 4.1 基础数据

- 学校 A：1 管理员、2 教师、10 学生、2 专业、2 班级、3 课程。
- 学校 B：1 管理员、1 教师、1 学生、1 课程；用于跨校隔离。
- 课程：语文教学论、数学教学论、英语教学论；教师组 1—2 人；学生分布两个班级。
- 任务：
  - 自由试讲（已发布，五维权重 30/20/20/15/15）；
  - 情景模拟（已发布）；
  - 结构化面试（已发布，2 题 / 5 分钟，三维 40/30/30）；
  - 草稿任务、已关闭任务、归档课程任务。
- 提交件：3—5 条，覆盖 completed / pending_ai / pending_teacher / ai_partial / ai_failed。
- M7：任务评分配置 70/30、维度 / 总分模式、教师评分、最终分、排行榜、CSV。
- M6：进阶 / 模拟考核模板、自由训练、3 条记录上限、过期记录。
- M5：种子题库 + 1 个演示类别；空题库学校用于边界。
- 录像：短 WebM fixture（camera / screen / audio），循环引用；固定 UUID。

### 4.2 边界数据

- 无在课学生的课程；空题库；题目停用 / 无答案要点；材料扫描 PDF。
- 课程 `end_at` 已过、已归档；任务关闭；草稿任务。
- 学生退课 / 转班；教师被移出老师组；管理员未绑定学校。
- 评测 partial / failed；训练记录过期 / 第 4 条；临时录像 5 个 attempt。
- 跨校资源 ID；伪造 JWT；过期 WS ticket；过期预签名 URL。

### 4.3 数据重置

- 集成测试：每个测试事务回滚；涉及异步任务时使用独立 schema / 数据库。
- E2E：每次运行重建演示数据；MinIO bucket 前缀隔离。
- 性能：独立环境；测试前后清理；不与其他测试共享 Redis Stream。

## 5. Mock 与可替换适配层

### 5.1 AI / OCR / ASR

- Python 适配层支持 `AI_MOCK=true`：
  - 返回固定维度分、子项分、问题、建议；
  - 根据 `evaluation_id` 稳定生成分数（同一输入可复现）；
  - 支持模拟 `partial`（缺 board）、`failed`、超时、非法 JSON。
- 真实模型调用只在 staging / 手工验收；CI 不依赖外部网络。
- OCR / ASR fixture：固定文本、置信度、时间戳；覆盖低置信、空结果。
- 视觉 LLM：固定关键帧描述；不真实上传图片到外部。

### 5.2 录制 / 回放

- 浏览器测试使用 `--use-fake-device-for-media-stream`、`--use-fake-ui-for-media-stream`。
- 屏幕共享在 headless 下不可用：课堂 E2E 使用 mock `getDisplayMedia` 或预置 WebM fixture。
- 录制上传测试使用小文件；MinIO Testcontainer。
- 回放同步用固定 WebM + 已知时长；检查 seek / drift 逻辑，不依赖真实摄像头。

### 5.3 WebSocket / Redis

- WS test client：连接、ticket、snapshot、命令、事件、关闭码。
- Redis Streams：Testcontainer；检查 XADD / XREADGROUP / XACK / pending / dead。
- 队列重试使用可控时钟，不等待真实退避。

### 5.4 时间

- `Clock` 注入；课程 `end_at`、记录 1 个月、临时录像 24 小时、评测退避均可推进。
- 不依赖系统当前时间；测试数据使用固定 UTC 时间。

### 7.1 课程任务闭环

- 使用 k6 / Gatling 或自定义 WS 压测；记录 CPU / 内存 / 队列深度。

- 失败标准：课堂掉线、事件丢失、录制不完整、M4 超时。

### 8.2 可靠性

- worker 崩溃 / 重启：Redis pending 认领，评测重试，不丢任务。
- Java 重启：`in_progress` session 标记 failed；未提交录像可清理。
- Redis 不可用：评测 job 保持 queued；恢复后重投。
- MinIO 不可用：录制 / 上传失败明确提示；不产生半份提交。
- 回调失败 / 重复：幂等；不重复计分。
- 队列积压：告警 / 暂停 XADD；恢复后处理。
- 网络抖动：控制 WS 断开进入 30 秒 grace；超时 / 页面刷新 / 录制器丢失 → failed；感知 WS 断线仅影响 ASR / OCR，录制继续。

### 8.3 安全

- JWT 篡改 / 过期 / 错误签名 → 401。
- 网关：通过 Nginx 直接访问登录 / 注册 / 公开选项成功；受保护 API 无 token 401；`/ws/` 用 ticket 握手成功。
- URL 权限：无权限接口 403；管理员访问 M3 / M4 / M6 / M7 403。
- 资源级越权：改 ID 访问他人课程 / 任务 / 提交 / 报告 / 训练记录 → 403 / 404。
- 训练隐私：教师用已知 training session / evaluation ID 访问通用 session / replay / texts / events / recordings / report / issues → 403 / 404。
- 跨校：全部 403；不泄露资源存在。
- WS ticket：一次性、过期、跨 session → 4001 / 403；30 秒 grace 重连成功；页面刷新失败。
- 预签名 URL：过期后不可下载；不暴露 bucket。
- 上传：类型 / 大小 / 文件名 / 路径穿越；扫描 PDF 失败。
- Prompt injection：参考材料 / 转写中的指令不改变评测行为。
- XSS：用户输入 / 题干 / 评语不执行脚本；不使用 `v-html`。
- CSV 注入：以 `= + - @` 开头的字段前置单引号 / 转义。
- 登录爆破：限流；错误信息不区分账号。
- 邮箱验证码：固定窗口重放、过期、尝试超限、跨邮箱使用、未绑定邮箱登录 → 统一失败；限流 429。
- 微信 OAuth：state / ticket 重放、过期、伪造 code、回调 redirect 篡改、provider token 泄漏 → 拒绝；绑定唯一性冲突 409。
- 登录审计不记录验证码、JWT、微信 access token；日志不输出明文邮箱验证码。
- 依赖漏洞 / 密钥扫描。

### 8.4 兼容性与可访问性

- Chrome / Edge 最新两个版本；Safari 不支持录制 / 回放。
- 1280×720、1440×900、1920×1080；最小 1024 宽。
- 键盘：Tab / Enter / Esc；抽屉 / 对话框焦点陷阱。
- axe-core：关键页面无 serious / critical。
- 对比度：正文 / 按钮 / 状态标签。
- `prefers-reduced-motion` 下关闭非必要动画。
- 面试 / 课堂倒计时 `aria-live`。

### 8.5 数据与迁移

- Flyway 从空库完整迁移；从上一版本增量迁移。
- JSONB、部分唯一索引、`FOR UPDATE` 在 PostgreSQL 16 验证。
- UUIDv7 生成 / 固定 seed UUID。
- 级联：删除 submission / training_record 清理 M4 / M7 从属数据。
- 保留期清理：临时 24h、任务课程结束 +1 年、训练 1 个月、M7 同期。
- 清理失败重试；先 MinIO 后 DB。
- 备份 / 恢复演练（staging）。

## 11. 缺陷分级与处理

| 级别 | 定义 | 处理 |
|---|---|---|

| Critical | 重要功能失败、评测 / 录制丢失 | 修复后发布 |
