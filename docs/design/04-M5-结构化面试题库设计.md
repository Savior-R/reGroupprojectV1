## 1. 范围

### 1.1 本轮实现

- 每校一个结构化面试题库
- 建校时复制种子题库；已有学校首次访问时懒初始化
- 类别管理：新增、编辑、排序、启停
- 题目管理：题干、答案要点、所属类别、启停

- 学校隔离、权限、审计、搜索、分页
- demo-only 一键初始化本校题库（不进入生产）

- 学生访问题库
- 跨校共享
- AI 生成题目 / 答案要点
- 学段、学科、难度、标签
- 随机抽题

## 2. 模块架构

```text
com.shijiangtai
└── m5question/
    ├── api/                 # QuestionBankController, CategoryController, QuestionController
    ├── application/         # QuestionBankService, CategoryService, QuestionService, SeedService
    ├── domain/              # Library, Category, Question
    ├── infrastructure/      # repositories, seed loader
    └── dto/
```

- `m5question` 依赖 M1 的学校与账号；不依赖 M2 / M3 / M4 / M6 / M7。
- M3 通过 `QuestionBankQueryService` 只读获取类别与题目，不直接操作 M5 表。
- M4 不直接读取 M5，使用 M3 任务配置快照中的题干与答案要点。
- 公开接口只暴露 Java；无 Python 参与。

## 3. 数据模型

沿用 01：

| 表 | 说明 |
|---|---|
| `m5_question.libraries` | 每校一个；`school_id` 唯一；`seed_version` |
| `m5_question.categories` | `school_id`、名称、排序、状态、审计 |
| `m5_question.questions` | `school_id`、`category_id`、题干、答案要点、状态、审计 |

约束：

- `UNIQUE(libraries.school_id)`。
- `UNIQUE(categories.school_id, name)`。
- 题目只属于一个类别、一个学校；类别停用后题目不可被新任务选择，但已选中的启用题目允许发布。
- 类别名称 1—50 字，校内唯一。
- 题干 / 答案要点非空；默认长度 500 / 2000。
- 状态 `active / disabled`；停用不物理删除。

## 4. 种子复制与初始化

### 4.1 种子内容

- `backend/src/main/resources/seed/question-bank.json`：
  - `seed_version`；
  - 类别数组：`name`、`sort_order`；
  - 题目数组：`category`、`stem`、`answer_points`。
- 种子内容由需求方提供；本轮可用示例数据占位。

### 4.2 建校时复制

- M1 创建学校成功后发布 `SchoolCreatedEvent`。
- M5 使用 `@TransactionalEventListener(AFTER_COMMIT)` 监听：
  1. `ensureLibrary(schoolId)`；
  2. 若 `libraries` 不存在，创建 library，写 `seed_version`；
  3. 复制类别与题目；`created_by / updated_by` 写 NULL，前端显示“系统”；
  4. 唯一约束 `libraries.school_id` 保证幂等。
- 种子复制失败不阻塞建校；记录失败日志，首次访问时重试。

### 4.3 已有学校懒初始化

- `QuestionBankService.ensureLibrary(schoolId)` 在首次读 / 写题库时调用；
- 没有 library 则按同样逻辑复制种子；
- 幂等；并发初始化由 `libraries.school_id` 唯一约束兜底。

### 4.4 种子版本

- `libraries.seed_version` 记录复制时的版本；
- 后续种子升级不自动同步已建学校；
- 新建学校使用最新种子；
- 后续如需同步，另做“导入种子题”功能，本轮不做。

## 5. 类别管理

- `GET /api/v1/question-bank/categories`：本校类别，按 `sort_order`；
- `POST`：新增类别；名称校内唯一；
- `PATCH /{id}`：编辑名称 / 排序 / 启停；
- 类别停用：
  - 不再出现在 M3 选题列表；
  - 已有任务快照不受影响；
- 类别下仍有题目时不能删除；本轮只提供停用；
- 审计：`created_by`、`updated_by`、`created_at`、`updated_at`。

## 6. 题目管理

- `GET /api/v1/question-bank/questions`：
  - 过滤：类别、状态、关键词（题干 / 答案要点）；
  - 分页 `page/size`；
- `POST`：新增题目；
- `PATCH /{id}`：编辑题干、答案要点、所属类别、启停；
- 校验：
  - 类别属于本校且启用；
  - 题干、答案要点非空且长度合规；
  - 跨校 403；
- 题目可移动到本校另一个类别；
- 停用题目：
  - 不进入 M3 新任务选题列表；
  - 已发布任务快照不受影响；
- 并发编辑：本轮最后写入生效；保留最后编辑人；不做版本历史（P1）；
- 搜索：先 `ILIKE`；需要模糊搜索再加 `pg_trgm`。

## 7. M3 选题接口

- **前端选题**：M3 使用公开 `GET /question-bank/categories`、`GET /question-bank/questions`，只返回启用类别下的启用题目；教师可搜索、分页、预览答案要点。
- **发布校验**：M3 调用内部 `QuestionBankQueryService`：
  - `listCategories(schoolId)`：启用类别；
  - `listQuestions(schoolId, categoryId?, keyword, page, size)`：启用题目；
  - `getQuestion(schoolId, questionId)`：题干、答案要点、类别；
- M3 手动选择 1—10 道题、排序、设置总时长 1—60 分钟。
- 发布任务时 M3 按 05C 的规范写入 `question_id`、`order`、`stem`、`answer_points`、`category_id`、`category_name`，并写入 `question_count`、`total_duration_seconds`；05C 的快照 JSON 为唯一规范。
- 类别停用只影响新选题；已选题目只要本身启用且答案要点非空，允许发布；新任务只显示启用类别下的题目。
- M5 不保存 M3 任务、提交件或评测。
- 题库为空、题目不足、题目停用、答案要点缺失时，M3 阻止发布。
- M5 不可用时，M3 不能新建结构化面试任务；已发布任务按快照继续。

### 7.1 独立演示

- 仅 `demo` profile 启用：`POST /api/v1/admin/question-bank/demo-init`，权限 `question_bank:manage`。
- 行为：对当前管理员学校执行 `ensureLibrary` + 复制演示种子；已存在则幂等返回。
- 演示数据使用同一套类别 / 题目接口与校验；不写入生产学校。
- 生产 profile 不注册该端点；调用返回 404。
- 种子复制：跳过答案要点为空的题目并记录日志；类别按名称去重；并发懒初始化由 `libraries.school_id` 唯一约束兜底，冲突时读取已有 library。

## 8. 权限与可见性

| 操作 | 学生 | 教师 | 管理员 |
|---|---|---|---|
| 查看题库 | 不可 | 本校 | 本校 |
| 管理类别 / 题目 | 不可 | 本校全部 | 本校全部 |
| M3 选题 | — | 本校 | — |
| 查看答案要点 | 不可 | 可 | 可 |
| 跨校访问 | 不可 | 不可 | 不可 |

- 权限码：`question_bank:read`、`question_bank:manage`。
- 学生导航不出现“题库资源”；直接访问返回 403。
- 答案要点只对教师 / 管理员可见；M3 学生界面不返回。

## 9. 页面与路由

| 路由 | 页面 | 角色 | 主要接口 |
|---|---|---|---|
| `/question-bank` | 结构化面试题库 | 教师、管理员 | 类别 / 题目 CRUD |
| `/question-bank/categories` | 类别管理抽屉 / 弹窗 | 教师、管理员 | 类别 CRUD |
| 题目编辑抽屉 | 新增 / 编辑题目 | 教师、管理员 | 题目 CRUD |

页面布局：

- 顶部导航“题库资源”；
- 左侧类别栏（教育理念 / 班级管理 / 应急应变等）；
- 右侧题目表格：题干、类别、状态、更新时间、操作；
- 题目编辑抽屉：题干、答案要点、类别、状态；
- 类别管理弹窗：名称、排序、启停；
- 空态：题库为空时提示“先添加题目或等待种子初始化”，M3 不可创建结构化面试任务；
- 视觉：B · 深蓝 + 琥珀；顶部导航；头像在右。

## 10. 事务、并发与审计

| 场景 | 处理 |
|---|---|
| 建校复制种子 | 单事务；`libraries.school_id` 唯一；失败不阻塞建校 |
| 懒初始化 | 单事务；唯一约束幂等 |
| 类别新增 / 编辑 | 单事务；名称唯一 |
| 题目新增 / 编辑 | 单事务；类别校验 |
| 并发编辑 | 最后写入生效；保留最后编辑人 |
| 停用 | 更新状态；不删除历史 |

## 11. 错误码

- `QUESTION_BANK_EMPTY`：题库为空 / 可用题目不足；
- `QUESTION_DISABLED`：题目已停用；
- `ANSWER_POINTS_MISSING`：答案要点缺失；
- `QUESTION_IN_USE`：类别 / 题目被引用，不能删除；
- `DUPLICATE_RESOURCE`：类别名称重复；
- `FORBIDDEN` / `CROSS_SCHOOL_ACCESS`：跨校 / 学生访问。

## 12. 测试与验收

- 建校自动复制种子；已有学校首次访问懒初始化；重复初始化不重复。
- 类别 / 题目 CRUD；名称唯一；停用后 M3 不可选；已有任务快照不受影响。
- 学校隔离；学生 403；跨校 403。
- M3 选题：1—10 道、排序、1—60 分钟；题库为空 / 题目不足 / 答案要点缺失阻止发布。
- 种子复制失败不阻塞建校，首次访问重试。
- 搜索 / 分页；停用类别下的题目不返回。
- 题目编辑 / 停用不影响已发布任务。
