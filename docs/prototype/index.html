DESIGN THESIS

四个关键词，一套界面。

不是把 Element Plus 换一套颜色，而是重新安排信息出现的顺序：先看见什么，再做什么，最后留下什么。

01 / PAPER

纸感

米白纸色、极细纹理、低对比边界。靠留白、字距和 1px 线建立秩序，而不是靠厚重阴影和渐变。

02 / INK

墨色

墨绿承担主操作，朱砂只做批注与重点，赭石提醒时间与风险。颜色有语义，不靠大面积高饱和色制造“活力”。

03 / STAGE

双舞台

普通页面是明亮的“讲义”，课堂 / 面试 / 回看是深色的“舞台”。同一套语义 token，不同的注意力密度。

04 / RHYTHM

节奏

标题、任务卡、表单分节、评测建议都有编号和层级。页面像一份可读的教案，而不是一组互不相干的卡片。

WHAT CHANGED

从“能点”到“知道下一步”。

现有页面已经具备完整功能，但层级、上下文和状态表达不一致。重构优先处理这四类问题。

现在 / BEFORE观察
导航缺少空间上下文

进入课程任务、评分、统计后，只能靠标题猜测自己在哪一层；课程内二级导航缺失。

页面是卡片堆叠

标题、筛选、表格、空态都在同一张 Card 里，主操作和辅助信息没有拉开层级。

深浅主题残留

浅色页面里仍有深蓝底、亮橙渐变和硬编码色值，和 `style.css` 的学术主题不一致。

关键流程缺少“下一步”

任务详情只有“查看详情”，课前检查、设备状态、开始入口和录制风险提示不够集中。

重设计后 / AFTER策略
顶部导航 + 课程上下文条

面包屑和课程内二级导航固定在内容上方；任务 / 评分 / 统计共享同一课程上下文。

先标题，再摘要，再内容

页面标题区独立于卡片；关键数字用 stat strip；列表、表单、建议各有稳定版式。

语义 token + 双舞台

普通页统一浅色学术主题；沉浸页切换为墨夜 + 琥珀；所有颜色来自 `tokens.css`。

每个页面有一个明确主行动

任务详情 → 开始试讲；课堂 → 结束试讲；回看 → 提交；报告 → 定位回放；评分 → 保存。

ITERATE

这不是一张定稿，
而是一条可调的基线。

所有页面都是静态 HTML + 一份共享 CSS / JS。先改 token，再改页面内的局部 `<style>`；不需要构建，也不需要后端。 设计决策、与现有路由的映射、待确认事项都写在 `docs/prototype/README.md` 与根目录 `DESIGN.md`。

调整设计 token 查看设计契约
01

先调全局气质

编辑 assets/tokens.css：纸色、墨绿、朱砂、字体、圆角、阴影。所有页面会同步变化。

02

再调单页编排

每页顶部都有局部 <style>，只负责该页的网格、卡片和特殊组件；不会互相污染。

03

最后记录决策

在 README.md 的迭代记录里写清“改了什么 / 为什么 / 影响哪些页面”，方便后续落到 Vue。
