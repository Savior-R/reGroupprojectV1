FOUNDATION / DESIGN SYSTEM

一套可被反复使用的
教学界面语言。

这份设计系统只定义“最小必要规则”：色彩、字体、间距、按钮、表单、状态和舞台。页面可以有个性， 但必须共用同一套语义。修改 token，再改页面；不要在每个页面里重新发明按钮。

“三尺讲台”是品牌名，也是产品气质。印章承担识别，衬线字承担学术感；不要给 Logo 加英文缩写或复杂图形。

09 / OVERLAYS

抽屉做任务，弹窗做确认。

评分、选题、配置用右侧抽屉；发布、删除、提交确认用居中弹窗。两者都有遮罩、焦点管理和 Escape 关闭。

Drawer / 抽屉560 / 880 WIDE

适合需要保留页面上下文的操作：教师评分、题库选题、评分配置。

Modal / 弹窗520

适合不可逆或需要二次确认的操作：提交试讲、发布任务、删除任务。

10 / STAGE

课堂是舞台，不是另一个后台。

沉浸页使用墨夜背景、琥珀主按钮、录制红状态；信息密度更高，但层级与普通页一致。

11 / ACCESSIBILITY

可读、可达、可恢复。

对比度、焦点环、键盘、状态文字和减少动效是基线，不是加分项。

Contrast≥ 4.5:1

正文用墨 900 / 纸 1；次文最低墨 500。朱砂只用于重点，不承载长段正文。

Focus2PX CINNABAR

所有按钮、链接、输入均可键盘到达；焦点环使用朱砂 2px，偏移 2px，不移除。

MotionPREFERS-REDUCED-MOTION

页面入场 380ms，控件 140—220ms；录制红点 1.6s 呼吸；减少动效时全部关闭。

12 / RULES

保持克制。

这套系统靠“少”而不是“多”成立。新增组件前，先确认现有组件真的不够用。

Do
  • 每个页面只保留一个主按钮；其余操作降级为次按钮或文字链接。
  • 先排版，再考虑装饰；留白和 1px 线优先于阴影、渐变和图标。
  • 状态用 badge + 文案；分数用 tabular numerals；时间用 mono。
  • 空态必须有图标、标题、解释和下一步；加载骨架与真实布局同形。
  • 沉浸页才用深色；普通页面保持浅色纸感。
Don't
  • 不要在每个页面里写新的按钮 / 卡片样式；先改共享类。
  • 不要用朱砂做大面积背景或长段文字。
  • 不要把卡片做成不同圆角、不同阴影的“拼贴”。
  • 不要用纯色块代替状态文字；不要让 Toast 承载关键错误。
  • 不要在沉浸页引入第三种主题色；深色只换语义别名，不换组件结构。
