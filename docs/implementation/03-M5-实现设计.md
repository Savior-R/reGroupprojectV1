## 4. 核心调用流程

### 4.1 建校复制种子

```mermaid
sequenceDiagram
  participant E as SchoolCreatedEvent
  participant L as QuestionBankSeedListener
  participant S as SeedService
  participant DB as Repositories
  E->>L: after commit
  L->>S: onSchoolCreated(schoolId)
  S->>DB: check libraries.school_id
  S->>DB: insert library(seed_version)
  S->>DB: insert categories + questions(created_by=null)
  alt 失败
    S-->>L: log; ensureLibrary 重试
  end
```

- 种子复制失败不阻塞建校；首次读 / 写调用 `ensureLibrary` 重试。
- `libraries.school_id` 唯一；并发冲突时读取已有 library。
- 跳过答案要点为空的题目；类别按名称去重；`created_by / updated_by = null`，前端显示“系统”。

### 4.2 类别 / 题目 CRUD

```text
CategoryController.create/update
  → QuestionBankApplicationService
  → 校验管理员 / 教师本校
  → 校验名称 1—50、校内唯一
  → insert/update categories（停用不删除）

QuestionController.create/update
  → 校验类别本校且启用
  → 校验 stem 1—500 / answer_points 1—2000
  → insert/update questions
```

- 题目只属于一个类别、一个学校。
- 停用题目不进入新任务选题；已发布任务按快照继续。
- 类别停用只影响新选题；已选中的启用题目允许发布。

### 4.3 M3 选题

```text
M3 前端
  → GET /question-bank/categories（启用类别）
  → GET /question-bank/questions（启用题目 / 分页 / 搜索）
  → 教师勾选 1—10 道、排序、设置总时长

M3 发布
  → QuestionBankQueryService.getForPublish(schoolId, ids)
  → 校验启用 / 答案要点非空 / 本校
  → TaskSnapshotFactory 写入题干 / 答案要点 / 顺序
```

- 公开 GET 只返回启用类别下的启用题目；不返回跨校。
- 发布时用内部 query service 再校验一次；快照以 05C 的 JSON 为准。
- 题库为空 / 题目不足 / 停用 / 无答案要点 → 422；M5 不可用 → 503。

### 4.4 Demo 初始化

```text
AdminQuestionBankController.demoInit
  → QuestionBankApplicationService.initDemo
  → 仅 demo profile
  → ensureLibrary + copySeed
  → 幂等；生产 profile 404
```

- 演示数据与生产种子隔离；不写入生产学校。

## 5. 权限与事件

- `question_bank:read`：教师 / 管理员本校；学生 403。
- `question_bank:manage`：教师 / 管理员本校。
- `SchoolCreatedEvent` after-commit；M5 监听。
- 跨校 / 学生访问 403；答案要点不返回学生。

## 6. 测试点

- 建校复制 / 懒初始化 / 并发唯一；种子失败不阻塞。
- 类别名称唯一 / 停用；题目长度 / 空答案要点。
- M3 选题 1 / 10 / 11；停用 / 跨校 / 无答案要点。
- 发布快照不受 M5 后续编辑影响。
- demo 初始化幂等；生产 404。
- 学生 / 跨校 403。
