## 1. M6 后端：按 V16 个人模板模型迁移

路径：`server/src/main/java/com/shijiangtai/m6training/**`

- 个人模板库：
  - `GET/POST /api/v1/training/my-templates`
  - `GET/PATCH/DELETE /api/v1/training/my-templates/{template_id}`
  - `POST /api/v1/training/my-templates/from-publication`
  - `GET /api/v1/training/my-templates/{template_id}/task-config`
  - 30 个 active 模板额度、教师模板发布中配置锁定、删除软删除并清理关联记录 / 材料。
- 多课程发布：
  - `GET /api/v1/training/publications`
  - `POST /api/v1/training/my-templates/{template_id}/publications`
  - `POST /api/v1/training/publications/{publication_id}/unpublish`
- 学生可见发布：`GET /api/v1/student/training/templates`、`GET .../{publication_id}`；卡片 / 详情不返回权重、参考材料与 owner。
- 模板材料：`POST/DELETE /api/v1/training/template-materials`；模板材料由 `TrainingMaterialObjectReader` 复制，内存 / MinIO 两种实现，未改 M3 `MaterialObjectStorage`。
- 训练 session 三来源：
  - `publication_id`：校验发布、模板、课程、在课学生；
  - `template_id`：校验本人 active 模板；
  - 自由训练：档位 + 可选课题 / 材料。
  - 两条模板路径都写 `template_id` / `publication_id` / `course_id` 到 session meta；学生个人模板课程为 null。
- 记录：`TrainingRecord` 增加 `publication_id`，列表 / 详情视图同步。
- 对账：`TrainingTemplateReconciler` 按 publication 处理 `course_archived` / `teacher_removed` / `template_deleted`，并取消 preparing session。
- 枚举 wire 修复：`TrainingOwnerRole`、`TrainingTemplateStatus`、`TrainingTemplateSourceType` 补 `@JsonValue`，否则前端收到 `TEACHER` / `ACTIVE` / `MANUAL` 大写值。
- 迁移 `V18__m6_personal_template_followup.sql`：
  - 发布下架原因约束改为 `manual / course_archived / teacher_removed / template_deleted`；
  - 补 `DELETE /api/v1/training/my-templates/{template_id}` 权限并授予 student / teacher。

## 2. M6 前端：按 08 §12 重构

路径：`frontend/src/views/training/**`

- `types.ts` / `api.ts`：切换为 V16 wire 类型与端点（my-templates、publications、template-materials、publication 详情、session / record 的 `publication_id`）。
- `routes.ts`：新增 `/student/training/my-templates/new`、`/student/training/my-templates/:templateId/edit`、`/student/training/config`、教师 `/teacher/training/templates/new`、`/teacher/training/templates/:templateId`；`/student/training/free` 重定向到 `config?mode=free`。
- `TrainingHomePage.vue`：教师发布模板 / 我的模板 / 自由训练三组；发布卡片显示“已复制”，支持开始训练与复制到我的模板；我的模板支持开始、引用配置、编辑、删除；空态提示可从零创建。
- `TemplateTrainingConfigPage.vue`：按 `publicationId` 取公开配置、只调整虚拟学生、以 `publication_id` 创建 session；支持复制到我的模板。
- `TrainingConfigPage.vue`（新）：统一 `mode=template|free`；模板模式从我的模板开始训练；自由训练支持课题 / 材料 / 学生，并可引用我的模板带入课题、档位与学生。
- `TrainingTemplateEditorPage.vue`（新）：教师 / 学生共用新建与编辑；名称、档位、课题、教材版本、时长、五项权重、虚拟学生、参考材料；发布中教师模板仅允许改名并提示先下架；教师详情页含发布 / 下架列表与多课程发布弹窗；删除二次确认并说明级联影响。
- `TeacherTrainingTemplatesPage.vue`：个人模板列表、额度显示、筛选、查看 / 编辑 / 删除。
- `VirtualStudentEditor.vue`：新增 `disabled` 属性，供配置锁定场景禁用全部学生编辑。
- 移除旧的 `FreeTrainingConfigPage.vue`（被统一训练配置页替代）。

已知限制：现有自由训练创建 DTO 不接受时长 / 权重，前端引用我的模板时只带入课题、档位、虚拟学生；时长 / 权重仍走自由训练默认值，已在页面明确提示，未擅自扩展跨模块 DTO。
