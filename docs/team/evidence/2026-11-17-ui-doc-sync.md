## 2. 原型对齐要点

- 普通页面：浅色学术主题 A（米白纸 + 墨绿 + 朱砂）；课堂 / 面试 / 回看：墨夜 + 琥珀舞台。
- 课程详情不提供页内角色 / 课程切换；由登录角色、路由权限与 `?role=` 决定。
- 管理员专业 / 班级新增与编辑使用弹窗；管理员课程详情只读概览 / 学生 / 老师组，可编辑元数据、归档。
- 教师课程学生管理独立页面：筛选、添加 / 移出、学生成绩抽屉。
- 任务不做草稿；任务行可删除；模板引用使用搜索 + 分页窗口。
- 训练模板不提供归档；教师 / 学生模板支持删除；已发布教师模板删除前先下架。
- 学生可创建 / 复制模板；训练配置可引用全部我的模板；自由训练可带入模板配置并自由修改。
- 题库类别管理为独立仓库页；题目编辑器类别选择使用独立窗口。
- 学生成绩按课程聚合；课程成绩页无页内课程切换条。
- 可能增长列表分页；引用类列表搜索 + 分页 + 懒加载；数据展示不使用进度条。
