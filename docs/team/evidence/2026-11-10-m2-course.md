## 2. 实现结构

```text
server/src/main/java/com/shijiangtai/m2course
├─ domain/         Course, CourseStatus, CoursePolicy, CourseTeacher, CourseStudent,
│                  TeacherStatus, StudentStatus, JoinMethod, MajorId,
│                  CourseArchivedEvent, CourseTeacherRemovedEvent
├─ application/    CourseApplicationService(+Impl), CourseMembershipService(+Impl)
│  ├─ command/     CourseQuery, CourseSearchCriteria, CreateCourseCommand,
│  │               UpdateCourseCommand, MemberQuery, Patch
│  ├─ port/        CourseRepository, CourseMemberRepository, M1DirectoryPort, CourseEventPublisher
│  └─ view/        CourseCardView, CourseDetailView, CourseTeacherView, CourseStudentView,
│                  BatchAddStudentsResult, MajorBrief, TeacherBrief
├─ infrastructure/ persistence/CourseRepositoryAdapter, CourseMemberRepositoryAdapter,
│                  crossmodule/JdbcM1DirectoryAdapter, events/SpringCourseEventPublisher
└─ api/            CourseController, CourseMemberController, dto/*, error/M2ExceptionHandler
```

关键决定：

1. **持久化用 JdbcTemplate 显式 SQL，不建 JPA 实体。** 四张表都是「行 + 状态列」，聚合写回需要 `SELECT ... FOR UPDATE`（防止并发移出最后一名教师）与 `ON CONFLICT DO NOTHING` 的关联同步，显式 SQL 比 JPA 映射更短也更可控；读模型同源，避免实体 / DTO 双份。
2. **`CourseQueryService` 未独立建类。** 设计与提示词里的 `CourseQueryService` 只承担列表 / 详情读模型，其逻辑（角色折算检索条件、批量补名称、拼装卡片）全部在 `CourseApplicationServiceImpl.list/get` 内，公开接口仍是 `CourseApplicationService.list/get`。这是实现层合并，不改契约签名。
3. **M1 只读端口 + 直连只读 SQL。** M1 模块本分支不存在，`JdbcM1DirectoryAdapter` 只对 `m1_auth.*` 做 `SELECT`，端口签名按 `docs/design/02` 的账号查询契约设计；M1 落地后可整体替换为调用 `m1auth` 的应用查询接口，M2 业务代码不动。
4. **`end_at` 与归档是两个维度。** `isEnded(now)` 只由 `endAt` 判定；已结束仍可见、可读统计，但禁止加入 / 加人 / 编辑；归档后学生不可见、老师组只读。两者都不物理删除。
5. **PATCH 三态。** `UpdateCourseCommand` 用 `Patch<T>` 区分「未传」与「传值」，未传字段不改；`end_at` 传 `null` 视为不改（清空不开放，避免绕过 `INVALID_END_AT`）。
6. **事件 after-commit。** `SpringCourseEventPublisher` 通过 `TransactionSynchronization.afterCommit` 发布 `CourseArchivedEvent` / `CourseTeacherRemovedEvent`，未注册同步时直接发布，事件只带 ID。
7. **错误码走 shared `DomainException`。** 与 `15 代码规范` §2.6 一致；`M2ExceptionHandler` 只补一个 `MethodArgumentTypeMismatchException → 400`，不与其他模块的全局 advice 抢同一异常。

## 3. API 一览

| 方法 | 路径 | 角色 | 说明 |
|---|---|---|---|
| GET | `/api/v1/courses` | 全部 | `keyword / scope / status / page / size`；学生只返回本校 + 专业范围内启用课程 |
| POST | `/api/v1/courses` | 教师 | 建课，201 |
| GET | `/api/v1/courses/{id}` | 全部 | 详情，含 `can_manage / can_join / can_leave / can_archive / can_restore` |
| PATCH | `/api/v1/courses/{id}` | 本组教师 / 本校管理员 | 改名称、`end_at` |
| POST | `/api/v1/courses/{id}/archive` | 本校管理员 | 归档，204 |
| POST | `/api/v1/courses/{id}/restore` | 本校管理员 | 恢复，204 |
| GET | `/api/v1/courses/{id}/teachers` | 本组教师 / 本校管理员 | `include_history` |
| POST | `/api/v1/courses/{id}/teachers` | 本组教师 / 本校管理员 | 加教师，201 |
| DELETE | `/api/v1/courses/{id}/teachers/{accountId}` | 本组教师 / 本校管理员 | 移出，204，最后一名 422 |
| GET | `/api/v1/courses/{id}/students` | 本组教师 / 本校管理员 | 分页，`include_history` |
| POST | `/api/v1/courses/{id}/students/class` | 本组教师 / 本校管理员 | 按班级批量，返回 `total/success/skipped/errors` |
| POST | `/api/v1/courses/{id}/students/account` | 本组教师 / 本校管理员 | 按账号单个，204 |
| DELETE | `/api/v1/courses/{id}/students/{accountId}` | 本组教师 / 本校管理员 | 移出（软删除），204 |
| POST | `/api/v1/courses/{id}/join` | 学生 | 自主加入，204，重复 409 |
| POST | `/api/v1/courses/{id}/leave` | 学生 | 自主退出，204 |

查询参数名按 `application.yml` 的 `property-naming-strategy: SNAKE_CASE` 与前端对齐，多词参数显式写成 `@RequestParam(name = "include_history")`。
