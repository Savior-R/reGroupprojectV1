## 5. 目标与范围

### 5.1 P0 目标

- 提交 / 训练触发评测；`source_type + source_id` 幂等。
- 输入装配：M3 提交件、录像、事件、文本、OCR 帧、配置快照；`EvaluationInputManifest` 快照。
- 队列 / start / result / fail 协议；attempt、重试、退避、死信、worker reclaim。
- 五维 / 三维评分、权重合成、partial / failed / completed 语义、雷达图、问题定位、改进建议。
- 报告查询权限（本人 / 老师组 / 管理员 403 / 训练私有）；`EvaluationTerminalEvent` 发布 / 对账。
- Python capability / worker；Java 编排与持久化。

### 5.2 不做

- 教师评分、最终分、统计、排行榜、CSV（M7）。
- M3 课堂 / 录制实现、M6 训练 session、M7 读模型。
- 教姿教态 / 普通话专项（M4 本轮也不做）。
- 手动重跑 UI；只做自动重试与终态。

### 5.3 必须遵守的契约

- `EvaluationInputManifest` 必须足以复现：模型 / prompt 版本、配置快照、文本 / 帧 / 事件 / 录像引用。
- `EvaluationTerminalEvent` 是 M7 唯一触发源；partial / failed 也是终态，不得让 M7 永久 pending。
- 权重为 0 的维度缺失可 completed + warning；weight>0 缺失必须 partial 且无总分。
- 结果分数一位小数；问题 / 建议必须有时间点与维度。
- 不把答案要点、参考材料泄漏给学生。
- 任何契约变更先改文档并让 M3 / M7 / 架构 owner 确认。
