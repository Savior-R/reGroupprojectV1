# M5 结构化面试题库

> 上位文档：[需求规格说明书.md](需求规格说明书.md) 第 6 点（本轮只做结构化面试题库）

> 需求编号：`FR-M5-xx`
> 依赖模块：[M1 账号管理与身份认证](M1-账号管理与身份认证.md)
> 下游：[M3 虚拟课堂与录制](M3-虚拟课堂与录制.md) 结构化面试选题；M4 通过 M3 的任务快照使用答案要点

## 1. 范围

### 1.1 本轮实现

- 每所学校一个结构化面试题库资源库
- 建校时自动复制内置种子题库；已有学校首次访问时初始化
- 类别管理：新增、编辑、排序、停用
- 题目管理：题干、答案要点、所属类别、启用 / 停用
- 管理员和老师均可管理本校题库；老师可编辑本校全部题目
- 学校隔离：只能访问本校题库，跨校不可见
- 供 M3 按类别筛选、手动选题、调整顺序、设置题目数量与总时长
- M3 发布任务时快照所选题目题干与答案要点；后续编辑或停用不影响已发布任务
- 题库搜索、筛选与分页

### 1.2 本轮不做

- 教材原文、教案模板、板书模板、优秀试讲范例（后续扩展）
- 题目 CSV / Excel 导入导出（后续）
- 题目审核、版本历史、使用统计
- 学生访问题库
- 跨校共享题库
- AI 生成题目或答案要点
- 学段、学科、难度、标签（后续）
- 随机抽题（M3 改为教师手动选择）
- 题库评测（M4 负责）

## 2. 角色与依赖

| 角色 | 说明 |
|---|---|
| 管理员 | 管理本校题库的类别与题目 |
| 教师 | 管理本校题库的类别与题目；在 M3 结构化面试任务中选题 |
| 学生 | 不可访问 M5；只在 M3 面试中看到被选中的题干，不显示答案要点 |
| 系统 | 建校时复制种子题库、维护学校隔离、向 M3 提供只读选题数据 |

- M1 提供学校、账号与角色；M5 的所有数据按 `school_id` 隔离。
- M3 读取本校题库，手动选题；发布任务时把题干与答案要点写入配置快照。
- M4 不直接读取 M5，使用 M3 快照中的答案要点做内容评测。
- M5 不依赖 M2 / M4 / M6 / M7。
- M5 不可用时，不能新建结构化面试任务；已发布任务按 M3 快照继续运行。

## 3. 核心概念

### 3.1 数据对象

| 对象 | 关键字段 | 说明 |
|---|---|---|
| 题库资源库 Library | library_id、school_id、seed_version、created_at、updated_at | 每校一个；建校时创建 |
| 类别 Category | category_id、school_id、name、sort_order、status、created_by、updated_by、created_at、updated_at | 题目分类；学校内名称唯一 |
| 题目 Question | question_id、school_id、category_id、stem、answer_points、status、created_by、updated_by、created_at、updated_at | 每题只有题干和答案要点；属于一个类别、一所学校 |
| 种子题库 Seed | seed_version、内置类别、内置题目、答案要点 | 系统自带模板；建校时复制为学校独立数据 |
| M3 选题快照 | question_id、stem、answer_points、order | 由 M3 在任务发布时生成；不属于 M5 |

### 3.2 关系

- 一所学校对应一个资源库；一个资源库包含多个类别；一个类别包含多道题目。
- 一道题目只属于一个类别、一所学校。
- 建校时把种子题库复制为学校独立数据；复制后各校自行维护，互不影响。
- M3 只能选择本校、启用状态、答案要点非空的题目；发布时快照题干与答案要点。
- M5 与 M3 之间是只读引用关系；M5 不保存 M3 的任务、提交件或评测。

## 4. 业务规则

1. 每所学校有且只有一个资源库；`school_id` 来自 M1。
2. 新建学校时创建资源库并复制最新种子题库；已有学校首次访问时若没有资源库则按同样规则初始化；初始化幂等。
3. 资源库记录 `seed_version`；种子题库后续升级不自动同步到已建学校，新建学校使用最新种子；后续可提供手动导入，本轮不做。
4. 管理员和老师可新增、编辑、停用本校类别与题目；老师可编辑本校全部题目，不限创建人。
5. 学生不可访问 M5；跨校访问一律拒绝；管理员只能管理本校题库。
6. 类别名称在学校内唯一；类别可排序；停用类别后不再出现在 M3 选题列表中。
7. 题目只有题干、答案要点、所属类别、状态与审计字段；本轮不增加学段、学科、难度、标签。
8. 题干与答案要点必填；默认最大长度：类别名 50 字、题干 500 字、答案要点 2000 字。
9. 题目可改所属类别；类别停用时，其下题目不可被 M3 选择，但已有任务快照不受影响。
10. 类别与题目采用停用而非物理删除；类别下仍有题目时不能删除，只能停用；停用后新任务不可选。
11. 编辑或停用题目不影响已发布任务；M3 任务快照中的题干与答案要点保持不变。
12. M3 选题：教师按类别筛选，手动选择 1—10 道启用且答案要点非空的题目，可调整顺序，设置总时长 1—60 分钟；默认 2 道题 / 5 分钟。
13. M3 发布任务时，把 `question_id`、题干、答案要点、顺序、题目数量与总时长写入配置快照；同一任务所有学生同题。
14. 教师选中的题目在发布前被停用、删除或答案要点被清空时，阻止发布并提示重新选择。
15. 题库为空、题目数量不足、题目已停用或答案要点缺失时，M3 阻止创建结构化面试任务。
16. M3 对 M5 只读；M5 不写 M3 的任务、提交件或评测数据。
17. 种子复制失败不影响建校成功；系统记录失败并在首次访问时重试，初始化幂等。
18. 题目编辑保留 `created_by`、`updated_by`、`updated_at`；本轮不做版本历史，并发编辑最后写入生效。
19. 答案要点属于教师与系统可见内容；学生不可见；M4 只通过 M3 快照读取。
20. 题库数据随学校长期保留；题目停用不物理删除；学校不存在时题库不可访问。

## 5. 功能需求

### FR-M5-01 学校题库初始化（P0）

- 新建学校时创建资源库，并复制最新种子题库的类别与题目。
- 已有学校首次访问时若没有资源库，按同样规则初始化。
- 初始化幂等：重复触发不产生重复类别或题目。
- 记录 `seed_version`；复制后的数据归学校所有，可独立编辑。
- 异常：种子题库缺失、复制失败时记录错误并在下次访问重试；不阻塞学校创建。

### FR-M5-02 类别管理（P0）

- 管理员、老师可查看本校类别列表，按 `sort_order` 排序。
- 可新增、编辑名称与排序、停用 / 启用类别。
- 类别名称在学校内唯一；停用类别不出现在 M3 选题列表。
- 类别下仍有题目时不能删除，只能停用。
- 异常：名称为空或重复、跨校、学生访问、类别下仍有题目时删除，拒绝。

### FR-M5-03 题目管理（P0）

- 管理员、老师可查看本校题目，支持按类别、状态、关键词筛选与分页。
- 可新增、编辑题干、答案要点、所属类别，停用 / 启用题目。
- 题目必须属于本校一个类别；题干与答案要点必填并校验长度。
- 可把题目移动到本校另一个类别。
- 保存时记录 `created_by` / `updated_by`；不做版本历史。
- 异常：题干或答案要点为空、超长、类别不存在 / 已停用、跨校、学生访问，拒绝。

### FR-M5-04 学校隔离与权限（P0）

- 管理员、教师只能访问本校题库；跨校访问返回 403。
- 教师可编辑本校全部题目，不受创建人限制。
- 学生访问题库、类别或题目接口一律拒绝。
- 管理员不能访问其他学校题库。
- 异常：跨校、学生、未认证、角色不符，拒绝。

### FR-M5-05 种子题库（P0）

- 系统内置一套结构化面试种子题库，包含类别、题干与答案要点。
- 建校时复制为学校独立数据；复制后的编辑、停用不影响种子模板或其他学校。
- 记录 `seed_version`；已建学校不自动同步后续种子更新，新建学校使用最新种子。
- 种子题目与普通题目使用同一套字段与管理规则，`created_by` 记为系统。
- 异常：种子版本缺失、种子题目答案要点为空时不复制该题，并记录日志。

### FR-M5-06 供 M3 选题（P0）

- 向 M3 提供本校类别列表与题目列表；只返回启用类别下的启用题目。
- 题目列表包含 `question_id`、题干、答案要点、类别、顺序；答案要点仅供教师端与系统使用。
- M3 手动选择 1—10 道题、调整顺序、设置总时长 1—60 分钟；默认 2 题 / 5 分钟。
- M3 发布时生成题目快照；M5 不保存 M3 任务。
- 异常：题库为空、可选题目不足、题目已停用、答案要点为空时，M3 阻止发布。

### FR-M5-07 停用与引用保护（P0）

- 题目、类别采用停用而非物理删除；停用后不再出现在 M3 选题列表。
- 已发布任务继续使用 M3 配置快照，不受停用或编辑影响。
- 发布前被停用 / 删除 / 清空答案要点的已选题目，阻止发布并要求重新选择。
- 异常：删除有题目的类别、跨校停用、学生操作，拒绝。

### FR-M5-08 搜索、筛选与分页（P1）

- 题目支持按类别、启用状态、关键词搜索；结果分页。
- 类别支持按名称搜索。
- 搜索结果只包含本校数据。
- 异常：跨校、学生访问，拒绝。

### FR-M5-09 审计与并发（P1）

- 记录类别 / 题目的 `created_by`、`updated_by`、`created_at`、`updated_at`。
- 本轮并发编辑最后写入生效；P1 再评估版本号或修订历史。
- 异常：并发覆盖时以最后写入为准；反馈最后编辑人。

### FR-M5-10 独立演示（P0）

- 提供种子题库与演示数据，可在不启动 M3 / M4 的情况下浏览、维护题库。
- 演示数据与生产数据使用同一套接口与校验。
- 演示环境可一键初始化某校题库；种子数据不得进入生产学校。
- 异常：演示数据缺失、学校不存在时提示初始化。

## 6. 主要流程

### 6.1 建校与题库初始化

1. 管理员创建学校（M1）。
2. M5 创建本校资源库，复制最新种子题库。
3. 管理员或老师登录后看到本校类别与题目，可编辑或停用。

### 6.2 老师维护题库

1. 进入本校题库，按类别浏览或搜索题目。
2. 新增 / 编辑题干、答案要点、所属类别；或停用题目。
3. 新增 / 编辑 / 停用类别；有题目的类别不能删除。

### 6.3 M3 结构化面试选题

1. 教师在 M3 创建结构化面试任务。
2. 从本校题库按类别筛选，手动选择 1—10 道题，调整顺序。
3. 设置总时长 1—60 分钟；默认 2 题 / 5 分钟。
4. 预览题干与答案要点，发布任务；M3 生成题目快照。
5. 后续 M5 编辑或停用题目，不影响该任务。

### 6.4 学生面试

1. 学生按 M3 任务进入结构化面试。
2. 只看到题干，不显示答案要点。
3. 回答转写与事件进入 M4；M4 使用 M3 快照中的答案要点评测。

## 7. 权限矩阵

| 操作 | 学生 | 教师 | 管理员 |
|---|---|---|---|
| 查看本校题库 | 不可 | 可 | 可 |
| 新增 / 编辑 / 停用类别 | 不可 | 可（本校） | 可（本校） |
| 新增 / 编辑 / 停用题目 | 不可 | 可（本校全部） | 可（本校全部） |
| M3 结构化面试选题 | — | 可（本校） | — |
| 查看答案要点 | 不可 | 可 | 可 |
| 跨校访问 | 不可 | 不可 | 不可 |

## 8. 异常与边界

- 学校不存在或未初始化：提示初始化；不返回其他学校数据。
- 种子题库缺失或复制失败：记录错误、下次重试；不阻塞建校。
- 类别名称为空 / 重复：拒绝保存。
- 类别下仍有题目时删除：拒绝，提示先停用或移动题目。
- 题干或答案要点为空 / 超长：拒绝保存。
- 题目所属类别不存在或已停用：拒绝保存或移动。
- 跨校访问、学生访问：403。
- 题目停用：不再出现在 M3 选题列表；已发布任务不受影响。
- 发布前已选题目被停用 / 删除 / 清空答案要点：阻止发布并提示重新选择。
- 题库为空或可选题目不足：M3 阻止创建结构化面试任务。
- M5 不可用：不能新建结构化面试任务；已发布任务按快照继续。
- 并发编辑：最后写入生效，记录最后编辑人。
- 种子题库更新：不自动同步已建学校；新建学校使用最新种子。
- 学生查看答案要点：拒绝。

## 9. 验收要点

1. 新建学校自动获得一套本校题库，类别与题目来自种子题库且可独立编辑。
2. 已有学校首次访问时能初始化题库；重复初始化不产生重复数据。
3. 管理员和老师可新增、编辑、停用本校类别与题目；老师可编辑全部题目。
4. 题目只有题干和答案要点两个内容字段；类别、状态、审计字段完整。
5. 类别名称校内唯一；有题目的类别不能删除，只能停用。
6. 跨校访问、学生访问题库均被拒绝。
7. M3 可从本校题库按类别筛选、手动选择 1—10 道题、调整顺序、设置 1—60 分钟；默认 2 题 / 5 分钟。
8. M3 发布任务时快照题干与答案要点；M5 后续编辑或停用不影响已发布任务。
9. 题库为空、题目不足、题目停用或答案要点缺失时，M3 阻止发布。
10. 种子题库只用于建校初始化；各校编辑互不影响，后续种子升级不自动同步。
11. M5 可独立演示，不依赖 M3 / M4 运行。
