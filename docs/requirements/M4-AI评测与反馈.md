> 下游：[M7 教师评测与数据统计](M7-教师评测与数据统计.md)、M8 达标与认证（暂缓）可消费评测结果

## 1. 范围

### 1.1 本轮实现

- 学生对已提交试讲的异步 AI 评测
- 五个维度：教学内容、教学表达、课堂互动与控场、板书 / PPT（文字和结构）、时间管理
- 总分、维度分、雷达图
- 带时间戳的问题定位与文字改进建议
- 教师可调维度权重（任务级）
- 结构化面试使用三维独立模板

### 1.2 本轮不做

- 教姿教态（站姿、手势、眼神、面部表情）
- 普通话标准度
- 示范片段、视频示范、TTS 语音示范
- 逐句点评（本轮只做问题定位与改进建议）
- 自定义评分细则（本轮只调维度权重，子项固定）
- 实时评测（只评提交件）
- 人工复核（教师打分、排行榜、班级平均分、导出见 [M7 教师评测与数据统计](M7-教师评测与数据统计.md)）
- 达标认证（M8 暂缓）

## 2. 角色与依赖

| 角色 | 说明 |
|---|---|
| 学生 | 查看本人提交件的评测报告，点击建议跳转回放 |
| 教师 | 课程老师组；查看本课程学生提交件的评测报告；发布前可调权重 |
| 管理员 | 不查看评测报告（与录像权限一致） |
| 系统 | 异步评测任务、模型调用、结果落库 |

- M1 提供账号、角色、学校。
- M2 提供课程、课程老师组、学生有效关系。
- M3 提供 session、submission、录像、转写、OCR 帧、事件日志、任务配置快照、参考材料和权重。
- M6 训练模式复用本模块评测；训练报告仅学生本人可见，覆盖课程老师组规则。
- M7 读取本模块的评测总分、维度分与状态，用于教师评分和最终分合成；M4 不依赖 M7。
- 下游模块引用 `evaluation_id`，不复制评测数据。

## 3. 核心概念

### 3.1 数据对象

| 对象 | 关键字段 | 说明 |
|---|---|---|
| 评测 Evaluation | evaluation_id、source_type（task_submission / training_record）、source_id、submission_id（可空）、training_record_id（可空）、session_id、task_id（可空）、course_id（可空）、student_account_id、mode、status、total_score、weights、task_config_version（可空）、training_config_version（可空）、model_version、rubric_version、attempt_count、created_at、completed_at | 任务提交或训练记录一条；重试更新同一条 |
| 维度分 DimensionScore | evaluation_id、dimension、score、sub_scores、confidence | 0—100 |
| 问题 / 建议 Issue | issue_id、evaluation_id、dimension、start_ms、end_ms、severity、evidence、suggestion | 时间使用 session 相对毫秒 |
| 输入快照 InputSnapshot | evaluation_id、source_type、source_id、submission_id（可空）、training_record_id（可空）、recording_ids、text_ids、frame_ids、event_ids、task_config_version（可空）、training_config_version（可空） | 保证可复现；`text_ids` 指向统一文本流 |
| 权重 | 各模式适用维度及权重 | 任务级，发布前可调，发布后锁定 |

### 3.2 关系

- 一个提交件（submission）或一条训练记录（TrainingRecord）对应一条评测；以 `source_type + source_id` 幂等，重试更新同一 evaluation。
- 一条评测对应若干维度分和问题 / 建议。
- 评测依赖 M3 的 session、submission 与录制；训练评测依赖 M6 的 TrainingRecord 与模板快照。
- 结构化面试评测不使用板书 / PPT 和课堂互动维度；训练模式沿用同一套维度规则，报告仅学生本人可见。

## 4. 业务规则

1. 任务模式只评测学生提交的那一份录像；训练模式只评测学生选中的 TrainingRecord；临时录像不评测。
2. 评测异步执行；状态为 `pending / running / completed / failed / partial`。
3. 自由试讲 / 情景模拟评五个维度：教学内容、教学表达、课堂互动与控场、板书 / PPT、时间管理。
4. 结构化面试评三个维度：教学内容、教学表达、时间管理；课堂互动与控场、板书 / PPT 不适用。
5. 教学内容以任务配置快照中的参考材料为参照；自由 / 情景任务发布时已要求参考材料，结构化面试使用题目答案要点；训练模板使用模板快照中的完整参考材料，自由训练使用学生选填的参考材料，未提供时准确性标「不可评估」。
6. 教学表达评语速、停顿、口头禅、音量、流畅度；普通话标准度不做。
7. 课堂互动与控场使用事件日志和师生问答文本，由 LLM 打分；规则先统计提问次数、纪律事件、响应时间等客观量。
8. 板书 / PPT 常态分析使用每帧 OCR + 文本 LLM；关键帧（翻页、板书定稿、OCR 低置信、图表页）使用视觉 LLM；不做字迹工整度。
9. 时间管理由 LLM 根据转写和时间戳动态识别课堂阶段，不强制套用固定五段；对比推荐时长与最高时长，标记超时或提前结束。
10. 权重按模式配置：自由 / 情景默认 30 / 20 / 20 / 15 / 15；结构化面试默认 40 / 30 / 30；教师可在发布前调整，发布后锁定；系统按权重计算总分，LLM 只打维度分。
11. 报告包含总分、维度分、雷达图、带时间戳的改进建议；不做示范片段、视频或 TTS。
12. 改进建议默认 3—5 条，按严重程度排序；每条绑定时间区间和证据，点击跳转回放。
13. 报告可见性：任务提交报告为提交学生本人 + 课程老师组；训练报告仅学生本人可见，覆盖课程老师组规则；管理员均不可见。
14. 评测结果与模型版本、权重版本、任务配置版本一起保存，保证可复现。
15. 本轮不做教师手动重跑；失败由系统自动重试。重试更新同一 evaluation，`evaluation_id` 保持稳定。
16. `partial` 为终态：展示已完成维度分，缺失维度标「不适用 / 未完成」，不展示总分；建议只针对已完成维度。
17. 评测报告、录像与 M7 教师评分 / 最终分保留期一致：任务报告按课程结束 + 1 年；课程结束日期用 M2 `end_at`，未设置时用归档时间。
18. 训练评测以 `source_type = training_record`、`source_id = record_id` 落库；不生成 Submission，`task_id` 可空、`course_id` 可为目标课程或空；配置使用模板快照或自由训练默认配置。
19. 训练报告保留 1 个月，与 TrainingRecord 一致；不适用课程结束 + 1 年规则。
20. M7 对 `partial / failed` 的提交件不计算最终分、不纳入教师统计；本轮不提供手动重跑，后续按 P1 评估受控重跑。

## 5. 功能需求

### FR-M4-01 评测触发与任务（P0）

- 任务模式：学生提交后自动创建评测；以 `submission_id` 幂等。
- 训练模式：学生选中 TrainingRecord 后创建评测；以 `training_record_id` 幂等。
- 统一以 `source_type + source_id` 作为幂等键，不重复生成。
- 异步执行；状态可查询；失败自动重试（默认 3 次，指数退避）。
- 临时录像、未提交 session、未选中的训练不触发评测。
- 重试更新同一 evaluation 记录，不产生新的 `evaluation_id`。

### FR-M4-02 输入装配与数据契约（P0）

- 任务模式从 M3 拉取：提交件、session、录像（camera / screen / audio）、转写、OCR 帧、事件日志、任务配置快照、参考材料解析文本、权重。
- 训练模式从 M6 拉取：TrainingRecord、TrainingSession、模板配置快照（含完整参考材料）或自由训练配置（含可选参考材料）；不拉取 Submission。
- M4 自行计算音频特征（音量、停顿、语速）并选择关键帧；M3 提供 OCR 帧的 `frame_type`、`change_score`、置信度。
- 所有时间使用 session 相对毫秒；三路录制记录 `offset_ms`，MVP 允许 ±1 秒误差。
- 生成输入快照，记录 `source_type`、`source_id`、资产 ID、`task_config_version` / `training_config_version`、模型版本。
- 异常：录像缺失、转写失败、OCR 帧缺失时标记输入不完整。

### FR-M4-03 教学内容评测（P0）

- 子项：知识点准确性、逻辑清晰度、重难点把握、术语正确性、讲解完整度。
- 自由 / 情景：以教材原文或教案解析文本为参照，LLM 对比转写与参考材料。
- 结构化面试：以题目答案要点为参照，评估回答内容。
- 训练模板：以模板快照中的完整参考材料为参照；自由训练提供参考材料时评准确性，未提供时标「不可评估」，教学内容维度由逻辑、术语、完整度等子项计分，报告仍展示分数与雷达，但置信度降低。
- 每个问题给出时间区间与引用；参考材料缺失时准确性标「不可评估」。

### FR-M4-04 教学表达评测（P0）

- 子项：语速、停顿、口头禅、音量、流畅度。
- 使用转写时间戳和音频特征；规则计算客观指标，LLM 做质量评价。
- 普通话标准度不做，报告中明确标注。

### FR-M4-05 课堂互动与控场评测（P0，仅自由 / 情景）

- 子项：提问设计、反馈评价、纪律处理、互动节奏；引导、应急话术、鼓励性语言并入反馈质量。
- 事件日志提供提问次数、举手、回答、正确性标记、纪律事件、管理动作、响应时间。
- LLM 基于事件和师生问答文本打分，证据带时间戳。
- 结构化面试不使用本维度。

### FR-M4-06 板书 / PPT 评测（P0，仅自由 / 情景）

- 子项：结构清晰度、内容完整性、与讲解一致性、PPT 使用合理性。
- 常态：OCR 文字 + 文本 LLM。
- 关键帧：翻页、板书定稿、OCR 低置信、图表页，交给视觉 LLM（DeepSeek `deepseek-flash`）。
- 不做字迹工整度；图表 / 公式识别失败时降低置信度。
- 结构化面试不使用本维度。

### FR-M4-07 时间管理评测（P0）

- LLM 按转写和时间戳动态识别课堂阶段，不强制五段。
- 计算各阶段时长、占比、节奏；对比推荐时长与最高时长；标记超时、提前结束、某阶段过短或过长。
- 证据带时间区间。

### FR-M4-08 评分合成与雷达图（P0）

- LLM 返回适用维度分（0—100）与子项分，格式为 JSON。
- 系统按任务权重计算总分；各模式权重和为 100%，否则阻止发布任务。
- 自由 / 情景生成五轴雷达；结构化面试生成三轴雷达。
- 总分和维度分保留一位小数。

### FR-M4-09 改进建议（P0）

- LLM 基于维度分、问题定位和证据生成 3—5 条改进建议，按严重程度排序。
- 每条建议包含：时间区间、问题描述、证据、可执行的改进话术或做法。
- 不生成示范片段、视频或 TTS；不做逐句点评。

### FR-M4-10 报告查询与权限（P0）

- 任务报告：提交学生本人 + 课程老师组；训练报告：仅学生本人；管理员均不可查看。
- 报告从任务列表 / 提交列表进入；建议时间戳可跳转回放 A。
- 报告展示状态；失败时提示系统正在重试或已失败。
- partial 报告展示已完成维度分，缺失维度标「不适用 / 未完成」，不展示总分。

### FR-M4-11 结构化面试评测模板（P0）

- 三维：教学内容 40、教学表达 30、时间管理 30；教师可调整适用维度权重。
- 不使用课堂互动与控场、板书 / PPT 维度；报告为三轴雷达。
- 教学内容以题目答案要点为参照；题目 / 回答使用 M3 的 `interview.*` 事件与时间线。
- 报告格式与其他模式一致，但不显示不适用维度。

### FR-M4-12 异步执行、重试与可观测性（P0）

- 评测任务进入队列，由 worker 执行；支持超时、失败重试、部分成功。
- 默认重试 3 次，指数退避；本轮不提供教师 / 学生手动重跑。
- 记录模型、提示词版本、权重版本、任务配置版本、输入快照，便于复现与排查。
- 异常时标记 `failed / partial`，不向前端返回半成品总分。

## 6. 主要流程

### 6.1 提交后评测

1. 学生提交 → 创建 `pending` 评测（绑定 submission_id）。
2. 装配输入 → `running`。
3. 执行适用维度评测（可并行）→ 维度分与问题。
4. 按权重合成总分与雷达数据。
5. 生成改进建议 → `completed`。
6. 学生 / 课程老师组查看报告。

### 6.2 查看报告

1. 任务列表或提交列表 → 评测报告。
2. 查看总分、雷达、维度分、建议。
3. 点击建议时间戳 → 回放 A 对应位置。

### 6.3 结构化面试评测

1. 提交 → 创建评测。
2. 使用题目答案要点，评教学内容、教学表达、时间管理。
3. 报告使用三轴雷达，不显示课堂互动与板书 / PPT。

## 8. 异常与边界

- 提交件缺失或录像不完整：标记 `failed`；不返回总分。
- 转写 / OCR 失败：重试；仍失败则相关维度标 `partial` 或降低置信度。
- 参考材料缺失：任务模式不应发生（发布时必填）；训练自由模式未提供参考材料时，知识点准确性标「不可评估」。
- 结构化面试题目缺少答案要点：阻止任务发布或内容维度标低置信度。
- LLM 超时、返回格式错误：自动重试；多次失败标记 `failed`。
- 某个维度失败：该维度标「未完成」，整体 `partial`，不展示总分。
- 权重和不为 100%：任务发布被阻止。
- 结构化面试：互动与板书 / PPT 维度显示「不适用」，不计入总分。
- 管理员访问报告：403。
- 重复提交或重复触发：按 submission_id 幂等，不生成重复评测。
- 评测重试：更新同一 evaluation，`evaluation_id` 稳定，`attempt_count` 增加。

## 9. 验收要点

1. 学生提交后生成报告：总分、适用维度分、雷达图、3—5 条改进建议。
2. 每条建议带时间区间，点击可跳转回放。
3. 教师调整权重后，总分按权重变化；权重和不为 100% 时无法发布任务。
4. 自由 / 情景任务缺参考材料时无法发布；结构化面试使用题目答案要点。
5. 板书 / PPT 使用 OCR + 关键帧视觉分析，不做字迹工整度。
6. 时间管理由 LLM 动态识别阶段，不强制五段。
7. 结构化面试报告为三维（内容 / 表达 / 时间），不包含互动与板书 / PPT。
8. 学生本人与课程老师组可看报告，管理员不可看。
9. 评测失败自动重试；partial 展示已完成维度、不展示总分；evaluation_id 稳定。
10. 建议时间戳与 M3 session 相对时间一致，回放 seek 准确。
11. 报告保留期与录像一致，按课程结束 + 1 年计算。
