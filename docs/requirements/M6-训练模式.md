## 1. 范围

### 1.1 本轮实现

- 两档训练：进阶（progressive）、模拟考核（mock_exam）
- 学生独立入口，不依赖课程任务
- 教师从已发布自由试讲任务的设置发布训练模板，只对指定课程的在课学生可见
- 学生可引用教师模板，也可自由训练
- 模拟考核固定时长与评分权重，仍允许多次练习
- 学生可修改虚拟学生配置，但不能改时长与权重
- 多次练习，回看后选一次生成评测并保留；每个模板最多保留 3 条记录
- 训练录像与报告仅学生本人可见，保留 1 个月
- 复用 M3 的课堂、录制、事件，复用 M4 的评测与报告

### 1.2 本轮不做

- 入门：跟读训练、语音语调纠正
- 高阶：学生质疑、课堂混乱、设备故障
- 学生个人模板保存
- 教师查看学生训练录像、报告或使用情况
- 训练进度、等级解锁、达标认证（后续模块）
- 训练计入课程任务、作业或成绩
- 跨校训练模板
- 情景模拟、结构化面试任务作为训练模板来源
- 示范片段、TTS 示范

## 2. 角色与依赖

| 角色 | 说明 |
|---|---|
| 学生 | 开始训练、选择模板或自由训练、配置虚拟学生、回看、生成评测、保留 / 删除；训练结果私有 |
| 教师 | 从自己可管理的已发布自由试讲任务发布训练模板，选择训练档位与目标课程；不能查看训练结果与使用情况 |
| 管理员 | 不参与训练结果；学校 / 课程维护在 M1 / M2 |
| 系统 | 复用 M3 课堂与录制、M4 评测；维护模板、训练记录与保留期 |

- M1 / M2 提供账号、课程、课程老师组、在课学生关系。
- M3 提供课堂、录制、事件、session 状态机；训练 session 复用引擎，但 `session_type = training`，不属于课程任务。
- M4 提供评测与报告；训练报告仅学生本人可见，覆盖 M4 的课程老师组可见规则。
- M7 教师评测与统计不读取训练记录；训练结果不进入 M7 名单、统计或导出。

## 3. 核心概念

### 3.1 数据对象

| 对象 | 关键字段 | 说明 |
|---|---|---|
| 训练模板 TrainingTemplate | template_id、source_task_id、source_task_config_version、course_id、training_level、classroom_mode、config_snapshot、created_by、status、published_at | 来自已发布 / 已关闭自由试讲任务的完整配置快照；只对目标课程在课学生可见 |
| 训练会话 TrainingSession | training_session_id、session_type=training、task_id=null、student_account_id、template_id（可空）、course_id（可空）、training_level、effective_config_snapshot、status、started_at、ended_at、duration、recording_ids、evaluation_id（可空） | 复用 M3 Session 表；训练不属于任务，不生成 Submission |
| 训练记录 TrainingRecord | record_id、training_session_id、student_account_id、template_id（可空）、selected_at、evaluation_id、expires_at、status | 学生选中的训练；每模板最多 3 条，`expires_at = selected_at + 1 个月` |
| 有效配置快照 | 虚拟学生人数、五个参数、个性文本、时长、权重、课题 / 参考材料 | 每次训练开始时生成；模板训练引用完整参考材料，自由训练可选填课题与参考材料 |

### 3.2 关系

- 训练模板来源于一个已发布 / 已关闭的自由试讲任务；发布时生成完整配置快照。
- 一个模板可对应多个训练 session；一个学生可对同一模板多次训练。
- 学生从多次训练中选一次生成评测并保留；未选中的训练录像按 M3 临时录像规则清理。
- 训练 session 复用 M3 Session 表，`session_type = training`、`task_id = null`；不生成课程任务 Submission。
- 训练报告仅学生本人可见；教师只能管理模板，不能查看训练结果。
- M4 Evaluation 通过 `source_type = training_record` 与 TrainingRecord 关联。

## 4. 业务规则

1. 训练模式独立于课程任务；学生可直接开始，不需要教师发布任务。
2. 本轮只实现进阶、模拟考核两档；高阶、入门不做。
3. 训练模板来源仅限教师可管理的、已发布或已关闭的自由试讲任务；情景模拟、结构化面试任务不作为模板来源。
4. 模板发布时教师选择训练档位（进阶 / 模拟考核）与目标课程；教师必须同时能访问源任务、并在目标课程老师组。
5. 目标课程可以与源任务课程不同；模板对目标课程在课学生可见。教师被移出目标课程老师组或目标课程归档时，模板自动下架。
6. 模板发布时生成完整配置快照：课题、完整参考材料解析文本、虚拟学生配置、时长、权重；学生看不到参考材料，只看课题和虚拟学生状态。
7. 教师不能查看学生训练录像、报告或使用情况，只能发布、下架模板。
8. 学生可使用教师模板，也可自由训练；学生配置权限与教师相同：人数最多 30、五个 0—1 参数、个性文本；每次训练前可改；暂不保存个人模板。
9. 学生不能修改时长与权重，只能修改虚拟学生配置；进阶与模拟考核都适用。
10. 模拟考核：时长固定为模板的 `duration_max`（推荐时长 = 最高时长，不暂停，到点自动停止），权重取模板权重；自由模拟考核使用系统默认 20 分钟、默认权重。
11. 进阶：按模板或默认推荐时长 15 分钟、最高 20 分钟，到最高时长自动停止；权重取模板或默认 30 / 20 / 20 / 15 / 15。
12. 学生可无限次练习；回看后选一次生成评测并保留；每个模板最多保留 3 条训练记录，超出按最旧删除。
13. 自由训练没有模板，训练记录按 `(student_id, template_id=null)` 分组，同样最多 3 条。
14. 未选中的训练录像沿用 M3 临时录像规则：结束后保留 24 小时、最多 5 个临时 attempt；选中后生成 TrainingRecord。
15. 训练录像与报告仅学生本人可见；教师、管理员不可见；TrainingRecord 保留 1 个月，学生可提前删除。
16. 训练评测复用 M4，Evaluation 以 `source_type = training_record`、`source_id = record_id` 落库；不生成 Submission，`task_id` 为空，`course_id` 可为目标课程或空。
17. 训练 session 状态：`preparing → in_progress → ended → reviewing → selected → evaluated`；`cancelled / failed`。`selected` 表示学生选中并生成评测，`evaluated` 表示 M4 进入终态（completed / partial / failed）。
18. 模板发布时锁定配置快照；学生修改只影响本次训练，不改变模板；模板修改不影响已开始或已保存的训练。
19. 模板下架或学生退课后：不能新建训练；未选中的 session 丢弃；已选中的 TrainingRecord 在保留期内仍可查看。
20. 自由训练可选填写课题，并可选填教材原文或教案；提供参考材料时评知识点准确性，未提供时标「不可评估」，教学内容维度由逻辑、术语、完整度等子项计分，报告仍展示分数与雷达，但置信度降低。

## 5. 功能需求

### FR-M6-01 训练入口（学生，P0）

- 学生端提供独立的「训练」入口，与课程任务列表分开。
- 先选训练档位（进阶 / 模拟考核），再选教师模板或自由训练。
- 模板列表只展示学生当前在课课程下、对应档位、已发布的训练模板。
- 自由训练可选填写课题，并可选填教材原文或教案；虚拟学生默认 3 人、参数 0.5。
- 异常：无可用模板、课程已归档、学生不在课、模板已下架。

### FR-M6-02 教师发布训练模板（P0）

- 教师从自己可管理的已发布 / 已关闭自由试讲任务选择一套设置。
- 选择训练档位（进阶 / 模拟考核）与目标课程；教师须能访问源任务且在目标课程老师组。
- 目标课程可与源任务课程不同；发布时生成完整配置快照（含完整参考材料解析文本）。
- 可下架模板；模板下架或教师被移出目标课程老师组 / 课程归档时自动下架。
- 教师不能查看模板使用次数、学生训练录像或报告。
- 异常：源任务是草稿、源任务是情景模拟 / 结构化面试、教师无源任务权限、教师不在目标课程老师组、目标课程归档。

### FR-M6-03 学生引用模板 / 自由训练（P0）

- 选择模板后，以模板配置为起点。
- 学生可修改虚拟学生人数、五个参数和个性文本；不能修改时长与权重。
- 自由训练使用系统默认配置，同样可修改虚拟学生，并可填写课题、选填教材原文或教案；参考材料仅用于评测，不展示给教师或管理员。
- 每次训练开始时生成有效配置快照，随 session 保存。
- 异常：超过 30 人、参数越界、个性文本超长。

### FR-M6-04 进阶训练（P0）

- 复用 M3 自由试讲课堂，无提示。
- 按模板或默认推荐时长 15 分钟、最高 20 分钟，到最高时长自动停止。
- 权重取模板或默认 30 / 20 / 20 / 15 / 15。
- 可无限次练习；回看后选一次生成评测并保留，每模板最多 3 条记录。

### FR-M6-05 模拟考核（P0）

- 复用 M3 自由试讲课堂，但时长固定：推荐时长 = 最高时长 = 模板 `duration_max`，不暂停，到点自动停止。
- 评分权重固定为模板权重；自由模拟考核使用 20 分钟与默认权重。
- 学生可修改虚拟学生配置，不能修改时长与权重。
- 可无限次练习；回看后选一次生成评测并保留，每模板最多 3 条记录。

### FR-M6-06 训练评测与保留（P0）

- 学生从已结束的训练中选一次，生成 M4 评测并保留。
- 未选中的训练录像按 M3 临时规则清理（24 小时 / 最多 5 个临时 attempt）。
- 选中后生成 TrainingRecord，`expires_at = selected_at + 1 个月`；每个模板最多 3 条，超出按最旧删除；自由训练按 `template_id=null` 分组同样最多 3 条。
- 学生可提前删除自己的训练记录。
- 训练报告仅学生本人可见；教师、管理员不可见。
- 异常：训练录像缺失、评测失败、超过保留数量。

### FR-M6-07 权限与可见性（P0）

- 学生：只能查看自己的训练录像、报告和训练记录。
- 教师：只能发布 / 下架自己可管理任务的训练模板；不能查看训练结果或使用情况。
- 管理员：不能查看训练录像与报告。
- 跨校模板、跨校训练：本轮不支持。
- M4 的「课程老师组可看报告」规则不适用于训练报告。

### FR-M6-08 复用 M3 / M4（P0）

- 训练 session 复用 M3 Session 表，`session_type = training`、`task_id = null`；录像、转写、OCR、事件仍按 session_id 关联。
- 训练 session 状态为 `preparing → in_progress → ended → reviewing → selected → evaluated`；不进入 `submitted`。
- 训练不生成 Submission，不进入教师任务提交列表。
- 训练评测复用 M4，但 M4 Evaluation 使用 `source_type = training_record`、`source_id = record_id`；不依赖 submission_id。
- 训练录像可见性按 M6，不按 M3 的任务录像规则。

## 6. 主要流程

### 6.1 教师发布训练模板

1. 教师登录，选择自己可管理的已发布 / 已关闭自由试讲任务。
2. 选择「发布为训练模板」，选择训练档位与目标课程（须在自己老师组）。
3. 生成完整配置快照并发布；可随时下架。

### 6.2 学生训练

1. 学生进入「训练」，选择进阶 / 模拟考核。
2. 选择教师模板或自由训练；自由训练可填写课题、选填参考材料；按需修改虚拟学生配置。
3. 开始试讲：共享窗口、摄像头、麦克风，复用 M3 课堂。
4. 到最高时长或主动结束 → 回看训练录像。

### 6.3 学生选评测与保留

1. 在多次训练中选一次，生成 M4 评测。
2. 未选中的训练录像按 24 小时 / 5 个临时 attempt 清理；选中的生成 TrainingRecord。
3. TrainingRecord 保留 1 个月；每模板最多 3 条，超出按最旧删除。
4. 学生可手动删除训练记录。

## 8. 异常与边界

- 源任务是草稿、情景模拟 / 结构化面试、教师无权限、目标课程归档：阻止发布模板。
- 模板已下架、学生不在课、课程已归档：不能开始训练。
- 虚拟学生超过 30 人、参数越界、个性文本超长：阻止开始。
- 训练录像缺失或录制中断：本次失败，可重做。
- 评测失败：系统自动重试；仍失败则提示，不生成报告。
- 超过每模板 3 条训练记录：删除最旧的一条。
- 训练记录超过 1 个月：自动删除。
- 学生退课或模板下架：不能新建训练；未选中的 session 丢弃；已选中的记录保留期内可看。
- 教师 / 管理员访问训练录像或报告：拒绝。
- 自由训练没有参考材料：知识点准确性标「未评估」，报告仍展示分数与雷达，置信度降低。

## 9. 验收要点

1. 教师可从已发布 / 已关闭自由试讲任务发布训练模板，选择档位与目标课程；模板只对目标课程在课学生可见。
2. 教师看不到学生训练录像、报告或使用情况。
3. 学生可在训练入口选择进阶 / 模拟考核、教师模板或自由训练。
4. 学生可修改虚拟学生人数、五个参数和个性文本；不能修改时长与权重。
5. 模拟考核固定时长与权重，到点自动停止；进阶按模板 / 默认时长，到最高时长停止。
6. 学生可无限次训练，回看后选一次生成评测；每模板最多保留 3 条记录。
7. 训练录像与报告仅学生本人可见，保留 1 个月，可手动删除。
8. 自由训练提供参考材料时评知识点准确性；未提供时标「不可评估」，报告仍有分数与雷达。
9. 训练不计入课程任务、作业或成绩，不进入教师提交列表。
10. 训练评测以 `source_type = training_record` 落库，不生成 Submission。
