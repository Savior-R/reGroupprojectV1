> 依赖模块：[M1 账号管理与身份认证](M1-账号管理与身份认证.md)、[M2 课程操作与管理](M2-课程操作与管理.md)、[M3 虚拟课堂与录制](M3-虚拟课堂与录制.md)、[M4 AI 评测与反馈](M4-AI评测与反馈.md)

## 1. 范围

### 1.1 本轮实现

- 两档训练：进阶（progressive）、模拟考核（mock_exam）
- 学生独立入口，不依赖课程任务
- 教师和学生的**个人模板库**：每人最多 30 个生效模板，已删除模板不计数
- 教师从零创建个人模板（课题、教材版本、时长、权重、虚拟学生、参考材料）
- 教师把自己的个人模板发布到一门或多门课程；学生按在课课程看到已发布模板
- 学生可直接使用教师发布模板训练，也可复制为个人模板后修改、或从零创建个人模板
- 个人模板可用于训练；教师个人模板可用于新建任务时预填配置；任务直接发布
- 模板配置快照；学生训练时只能调整虚拟学生，不能覆盖模板的课题 / 时长 / 权重 / 参考材料
- 模拟考核按模板时长与权重固定执行；进阶按模板或默认时长
- 多次练习，回看后选一次生成评测并保留；每个模板最多保留 3 条记录
- 训练录像与报告仅学生本人可见，保留 1 个月
- 复用 M3 的课堂、录制、事件，复用 M4 的评测与报告

### 1.2 本轮不做

- 入门：跟读训练、语音语调纠正
- 高阶：学生质疑、课堂混乱、设备故障
- 模板分享、模板市场、学生之间互相复制模板
- 模板版本历史、多人协作编辑、模板导入导出
- 跨校训练模板
- 情景模拟、结构化面试任务作为训练模板来源
- 教师查看学生训练录像、报告或使用情况
- 训练进度、等级解锁、达标认证（后续模块）
- 训练计入课程任务、作业或成绩
- 示范片段、TTS 示范

## 2. 角色与依赖

| 角色 | 说明 |
|---|---|
| 学生 | 管理自己的个人模板；使用教师发布模板、复制为个人模板、从零创建；开始训练；回看、生成评测、保留 / 删除；训练结果私有 |
| 教师 | 创建个人模板；发布到一门或多门课程；用个人模板预填新任务（直接发布）；不能查看训练结果与使用情况 |
| 管理员 | 不参与训练结果；学校 / 课程维护在 M1 / M2 |
| 系统 | 复用 M3 课堂与录制、M4 评测；维护模板、发布、训练记录与保留期 |

- M1 / M2 提供账号、课程、课程老师组、在课学生关系。
- M3 提供课堂、录制、事件、session 状态机；训练 session 复用引擎，但 `session_type = training`，不属于课程任务。
- M3A 在创建任务时可读取教师自己的 M6 个人模板并预填配置；任务创建后与模板解耦。
- M4 提供评测与报告；训练报告仅学生本人可见，覆盖 M4 的课程老师组可见规则。
- M7 教师评测与统计不读取训练记录；训练结果不进入 M7 名单、统计或导出。

## 3. 核心概念

### 3.1 数据对象

| 对象 | 关键字段 | 说明 |
|---|---|---|
| 个人模板 PersonalTrainingTemplate | template_id、school_id、owner_account_id、owner_role、name、training_level、classroom_mode、source_type、source_template_id、source_publication_id、config_snapshot、status、archived_at | 教师 / 学生都可拥有的可复用配置；`active` 才可发布、复制、训练或预填任务；`archived_at` 为软删除时间；每人最多 30 个 active |
| 课程发布 TemplatePublication | publication_id、template_id、course_id、status、published_at、unpublished_at、unpublish_reason、created_by | 教师把个人模板发布给课程学生；一个模板可发布到多门课程；每门课程同时最多一条 published |
| 训练会话 TrainingSession | training_session_id、session_type=training、task_id=null、student_account_id、template_id（可空）、publication_id（可空）、course_id（可空）、training_level、effective_config_snapshot、status | 复用 M3 Session 表；训练不属于任务，不生成 Submission |
| 训练记录 TrainingRecord | record_id、training_session_id、student_account_id、template_id（可空）、publication_id（可空）、selected_at、expires_at、status | 学生选中的训练；每模板最多 3 条，`expires_at = selected_at + 1 个月` |
| 有效配置快照 | 虚拟学生人数、五个参数、个性文本、时长、权重、课题 / 参考材料 | 每次训练开始时生成；模板训练引用模板快照，自由训练可选填课题与参考材料 |

### 3.2 关系

- 个人模板属于一个账号；教师模板可发布到多门课程，学生模板不发布。
- 学生可从教师发布复制出新的学生个人模板；副本保存来源模板 / 发布 ID，之后与来源完全解耦。
- 教师可用自己的个人模板预填新任务并直接发布；任务创建后不依赖模板。
- 一个模板可对应多个训练 session；一个学生可对同一模板多次训练。
- 学生从多次训练中选一次生成评测并保留；未选中的训练录像按 M3 临时录像规则清理。
- 训练 session 复用 M3 Session 表，`session_type = training`、`task_id = null`；不生成课程任务 Submission。
- M4 Evaluation 通过 `source_type = training_record` 与 TrainingRecord 关联。

## 4. 业务规则

1. 训练模式独立于课程任务；学生可直接开始，不需要教师发布任务。
2. 本轮只实现进阶、模拟考核两档；高阶、入门不做。
3. 教师个人模板从零创建，不依赖已有任务；历史任务派生的模板保留 `source_type = task` 作为来源审计，仍可发布和使用，但不再新增此类模板。
4. 教师发布模板时选择目标课程；教师必须在目标课程老师组，模板与课程同校，课程 active 且未过 `end_at`。一个模板可发布到多门课程，每门课程同时最多一条 published 发布。
5. 模板对目标课程在课学生可见；教师被移出课程老师组、课程归档或模板删除时，相关发布自动下架。目标课程 `end_at` 已过时学生列表不再展示，但发布状态可保持 published。
6. 模板保存完整配置快照：课题、教材版本、时长、权重、虚拟学生、完整参考材料解析文本；学生使用教师发布模板时看不到参考材料与权重。
7. 教师不能查看学生训练录像、报告或使用情况，只能管理自己的模板与发布。
8. 学生可使用教师发布模板，也可复制为个人模板后修改，或从零创建个人模板；学生个人模板仅本人可见，可用于训练。
9. 个人模板的 owner 可修改名称、课题、教材版本、训练档位、时长、权重、虚拟学生、参考材料；训练 session 启动后不能覆盖模板的课题 / 时长 / 权重 / 参考材料，只能替换虚拟学生。教师发布模板的配置在有 published 发布期间锁定，教师需先下架再修改。
10. 模拟考核：模板的推荐时长必须等于最高时长；训练到点自动停止。学生可在自己的个人模板中自定义时长 / 权重；模拟考核的 session 仍按该模板固定执行。自由模拟考核使用系统默认 20 分钟、默认权重。
11. 进阶：按模板或默认推荐时长 15 分钟、最高 20 分钟，到最高时长自动停止；权重取模板或默认 30 / 20 / 20 / 15 / 15。
12. 每个学生 + 每个模板最多保留 3 条有效训练记录，超出按最旧删除；自由训练按 `(student_id, template_id=null)` 分组同样最多 3 条。复制教师模板会生成新的模板 ID，因此副本拥有独立的一组 3 条额度；30 个模板上限把总量约束在 90 条以内。
13. 自由训练没有模板，训练记录按 `template_id=null` 分组；学生可填写课题、选填参考材料、配置虚拟学生。
14. 未选中的训练录像沿用 M3 临时录像规则：结束后保留 24 小时、最多 5 个临时 attempt；选中后生成 TrainingRecord。
15. 训练录像与报告仅学生本人可见；教师、管理员不可见；TrainingRecord 保留 1 个月，学生可提前删除。
16. 训练评测复用 M4，Evaluation 以 `source_type = training_record`、`source_id = record_id` 落库；不生成 Submission，`task_id` 为空，`course_id` 可为目标课程或空。
17. 训练 session 状态：`preparing → in_progress → ended → reviewing → selected → evaluated`；`cancelled / failed`。`selected` 表示学生选中并生成评测，`evaluated` 表示 M4 进入终态（completed / partial / failed）。
18. 模板快照在创建 / 编辑时生成；训练开始时再生成 session 级 `effective_config_snapshot`。之后的模板修改不影响已开始或已保存的训练。
19. 模板下架 / 发布下架或学生退课后：不能新建使用该发布的训练；未选中的 session 丢弃；已选中的 TrainingRecord 在保留期内仍可查看。学生个人模板不因退课失效。
20. 参考材料可选；提供时评知识点准确性，未提供时标「不可评估」，教学内容维度由逻辑、术语、完整度等子项计分，报告仍展示分数与雷达，但置信度降低。
21. 每个账号（教师或学生）最多 30 个 active 个人模板；已删除模板不计数；课程发布不额外占额度。创建、复制模板时校验，超限返回 409。
22. 教师可用自己的 active 教师模板预填新建任务：复制课题、教材版本、时长、权重、虚拟学生与参考材料；任务直接发布，创建后独立，模板后续修改 / 删除不影响任务。任务记录 `source_training_template_id` 仅作来源追溯，不做权限或运行时依赖。
23. 模板删除为软删除：`status=archived`（内部软删除，UI 文案为删除），记录 `archived_at`；删除时自动下架全部发布、释放 30 额度，并清理该模板关联的 TrainingRecord（含课堂录像 / 评测报告）与模板参考材料，不保留；学生副本与任务快照不受影响；删除不可恢复。

## 5. 功能需求

### FR-M6-01 训练入口（学生，P0）

- 学生端提供独立的「训练」入口，与课程任务列表分开。
- 先选训练档位（进阶 / 模拟考核），再选教师发布模板、我的模板或自由训练。
- 教师发布模板只展示学生当前在课课程下、对应档位、published 且模板 active 的发布。
- 我的模板展示学生自己的 active 个人模板，不受当前课程限制。
- 自由训练可选填写课题，并可选填参考材料；虚拟学生默认 3 人、参数 0.5。
- 异常：无可用模板、课程已归档、学生不在课、发布已下架、模板已删除。

### FR-M6-02 个人模板管理（学生 / 教师，P0）

- 教师、学生都可从零创建个人模板，填写名称、档位、课题、教材版本、时长、权重、虚拟学生、可选参考材料；多角色账号可指定 `owner_role`，未指定取主身份，共用一个 30 额度。
- 一个模板固定一个档位；需要进阶 / 模拟考核两档时创建两个模板，各占 1 个 active 额度。
- 每人的 active 模板最多 30 个；超限阻止创建 / 复制。
- owner 可编辑模板全部配置；教师模板存在 published 发布时，除名称外的配置锁定，需先下架。
- owner 可删除模板；删除后不可用于新发布、复制、训练或任务预填。删除会清理该模板关联的训练记录、录像 / 报告与参考材料；学生副本与任务快照不受影响。
- 模板列表仅 owner 可见；管理员不可见。
- 异常：名称为空 / 超长、课题超长、时长越界、权重和不为 100、虚拟学生越界、参考材料解析失败、额度超限。

### FR-M6-03 教师发布模板（P0）

- 教师选择自己的 active 教师模板，发布到一门或多门课程。
- 教师须在目标课程老师组；模板与课程同校；课程 active 且未过 `end_at`。
- 同一模板 + 同一课程同时只允许一条 published 发布；重复发布返回 409。
- 可手动下架；课程归档、教师被移出课程老师组、模板删除时自动下架。
- 发布不复制模板；模板配置更新需先下架，再重新发布（新建发布记录，旧记录保留审计）。
- 教师不能查看模板使用次数、学生训练录像或报告。
- 异常：模板不是自己的、模板已删除、目标课程不可用、教师不在老师组、重复发布。

### FR-M6-04 学生复制 / 自建模板（P0）

- 学生可在教师发布模板卡片上「复制到我的模板」。
- 复制条件：发布 published、模板 active、课程 active 且未过 `end_at`、学生在该课程 active。
- 复制生成新的学生个人模板；深拷贝配置快照与参考材料对象；记录 `source_template_id`、`source_publication_id`。
- 副本因来源下架 / 删除 / 退课不受影响；副本 owner 可修改全部字段（含档位、时长、权重）。
- 学生也可从零创建个人模板；字段与教师模板一致。
- 额度超限返回 409；参考材料复制失败时复制整体失败，不留下半成品模板。
- 异常：发布不可见、模板已删除、额度超限、材料复制失败。

### FR-M6-05 进阶训练（P0）

- 复用 M3 自由试讲课堂，无提示。
- 按模板或默认推荐时长 15 分钟、最高 20 分钟，到最高时长自动停止。
- 权重取模板或默认 30 / 20 / 20 / 15 / 15。
- 训练开始时只能替换虚拟学生，不能覆盖模板时长 / 权重 / 课题 / 材料。
- 可无限次练习；回看后选一次生成评测并保留，每模板最多 3 条记录。

### FR-M6-06 模拟考核（P0）

- 复用 M3 自由试讲课堂，但时长固定：模板推荐时长 = 最高时长；不暂停，到点自动停止。
- 评分权重固定为模板权重；自由模拟考核使用 20 分钟与默认权重。
- 学生可修改虚拟学生配置；使用教师发布模板时不能改模板时长 / 权重，使用自己的模板时可在训练前编辑模板。
- 可无限次练习；回看后选一次生成评测并保留，每模板最多 3 条记录。

### FR-M6-07 训练评测与保留（P0）

- 学生从已结束的训练中选一次，生成 M4 评测并保留。
- 未选中的训练录像按 M3 临时规则清理（24 小时 / 最多 5 个临时 attempt）。
- 选中后生成 TrainingRecord，`expires_at = selected_at + 1 个月`；每个模板最多 3 条，超出按最旧删除；自由训练按 `template_id=null` 分组同样最多 3 条。
- 学生可提前删除自己的训练记录。
- 训练报告仅学生本人可见；教师、管理员不可见。
- 异常：训练录像缺失、评测失败、超过保留数量。

### FR-M6-08 权限与可见性（P0）

- 学生：只能查看 / 管理自己的个人模板；只能查看自己的训练录像、报告和训练记录；只能使用自己可见的教师发布模板。
- 教师：只能管理自己的个人模板与发布；不能查看学生训练结果或使用情况。
- 管理员：不能查看训练模板、训练录像与报告。
- 跨校模板、跨校训练：本轮不支持。
- M4 的「课程老师组可看报告」规则不适用于训练报告。

### FR-M6-09 复用 M3 / M4（P0）

- 训练 session 复用 M3 Session 表，`session_type = training`、`task_id = null`；录像、转写、OCR、事件仍按 session_id 关联。
- 训练 session 状态为 `preparing → in_progress → ended → reviewing → selected → evaluated`；不进入 `submitted`。
- 训练不生成 Submission，不进入教师任务提交列表。
- 训练评测复用 M4，但 M4 Evaluation 使用 `source_type = training_record`、`source_id = record_id`；不依赖 submission_id。
- 训练录像可见性按 M6，不按 M3 的任务录像规则。

### FR-M6-10 教师用模板预填任务（P0，跨 M3A）

- 教师在新建任务页可选择自己的 active 教师模板，预填课题、教材版本、时长、权重、虚拟学生与参考材料。
- 模板必须属于当前教师、`owner_role=teacher`、`status=active`。
- 预填后的任务直接发布；教师可在创建前修改配置，任务创建后不依赖模板。
- M3A 复制模板的参考材料到任务材料对象；复制失败则任务创建失败，不留下半成品。
- 任务记录 `source_training_template_id`，仅作来源追溯。
- 异常：模板不存在 / 非本人 / 已删除 / 材料复制失败。

## 6. 主要流程

### 6.1 教师创建并发布模板

1. 教师进入「我的模板」，从零创建模板：名称、档位、课题、教材版本、时长、权重、虚拟学生、可选参考材料。
2. 保存后模板为 active；可继续编辑。
3. 选择「发布到课程」，选择一门或多门课程（须在自己老师组）。
4. 发布后课程在课学生可见；教师可下架；课程归档 / 移出老师组 / 模板删除时自动下架。

### 6.2 学生复制 / 自建模板并训练

1. 学生进入「训练」，选择进阶 / 模拟考核。
2. 选择教师发布模板、我的模板或自由训练。
3. 教师发布模板可直接开始训练，或「复制到我的模板」后编辑副本。
4. 学生可编辑自己的模板全部字段；训练配置页只能调整虚拟学生。
5. 开始试讲：共享窗口、摄像头、麦克风，复用 M3 课堂。
6. 到最高时长或主动结束 → 回看训练录像。

### 6.3 教师用模板新建任务

1. 教师在课程内新建任务，选择「从训练模板填充」。
2. 选择自己的 active 教师模板；系统预填任务。
3. 教师补全课程 / 材料等必填项并发布任务。
4. 任务与模板解耦；模板后续修改 / 删除不影响任务。

### 6.4 学生选评测与保留

1. 在多次训练中选一次，生成 M4 评测。
2. 未选中的训练录像按 24 小时 / 5 个临时 attempt 清理；选中的生成 TrainingRecord。
3. TrainingRecord 保留 1 个月；每模板最多 3 条，超出按最旧删除。
4. 学生可手动删除训练记录。

## 8. 异常与边界

- 个人模板超过 30 个 active：阻止创建 / 复制，返回 409。
- 教师模板存在 published 发布时修改配置：阻止，提示先下架。
- 同一模板 + 课程重复发布：返回 409。
- 发布已下架、模板已删除、学生不在课、课程已归档：不能开始训练。
- 复制来源不可见 / 模板已删除 / 额度超限：阻止复制。
- 虚拟学生超过 30 人、参数越界、个性文本超长：阻止保存 / 开始。
- 时长越界、权重和不为 100、模拟考核推荐时长不等于最高时长：阻止保存。
- 训练录像缺失或录制中断：本次失败，可重做。
- 评测失败：系统自动重试；仍失败则提示，不生成报告。
- 超过每模板 3 条训练记录：删除最旧的一条。
- 训练记录超过 1 个月：自动删除。
- 学生退课或发布下架：不能新建使用该发布的训练；未选中的 session 丢弃；已选中的记录保留期内可看；学生个人模板不受影响。
- 教师 / 管理员访问训练录像或报告：拒绝。
- 自由训练没有参考材料：知识点准确性标「未评估」，报告仍展示分数与雷达，置信度降低。
- 任务预填时模板不可用 / 材料复制失败：任务创建失败，不生成任务。

## 9. 验收要点

1. 教师可从零创建个人模板，编辑、删除；每账号 active 模板不超过 30。
2. 教师可把同一模板发布到多门课程；学生只看到自己在课课程下的发布；下架 / 自动下架生效。
3. 学生可将教师发布模板复制为个人模板，也可从零创建；副本可修改全部字段，来源下架不影响副本。
4. 学生可在训练入口选择进阶 / 模拟考核、教师发布模板、我的模板或自由训练。
5. 训练配置页只能调整虚拟学生，不能覆盖模板的课题 / 时长 / 权重 / 参考材料。
6. 模拟考核按模板固定时长与权重执行，到点自动停止；进阶按模板 / 默认时长，到最高时长停止。
7. 学生可无限次训练，回看后选一次生成评测；每模板最多保留 3 条记录；复制产生的副本单独计 3 条。
8. 训练录像与报告仅学生本人可见，保留 1 个月，可手动删除。
9. 教师可用自己的 active 教师模板预填新任务并直接发布；任务创建后与模板解耦。
10. 训练不计入课程任务、作业或成绩，不进入教师提交列表。
11. 训练评测以 `source_type = training_record` 落库，不生成 Submission。
12. 自由训练提供参考材料时评知识点准确性；未提供时标「不可评估」，报告仍有分数与雷达。
