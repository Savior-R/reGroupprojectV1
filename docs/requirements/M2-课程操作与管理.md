## 1. 范围

### 1.1 本轮实现

- 教师创建课程（课程名称、一个或多个专业；专业须在教师本人专业范围内）
- 老师组：组内平权、可互相拉人；管理员可改 / 删成员
- 学生按本校与课程专业范围检索、加入、退出课程
- 教师按班级批量或按账号 ID 单个加入学生、移出学生
- 管理员管理本校课程（编辑 / 归档 / 恢复、老师组、学生名单），不能创建课程
- 课程级权限与可见性

### 1.2 本轮不做

- 小组训练
- 试讲任务发布（课时、学段、教材版本、评分标准）
- 教师批阅与课程数据统计（见 [M7 教师评测与数据统计](M7-教师评测与数据统计.md)；语音点评本轮不做）
- 课程物理删除
- 跨校课程、跨校教师组
- 课程专业范围修改（默认创建后不可改）
- 教师归档 / 删除课程（默认仅管理员可归档 / 恢复）

## 2. 角色与依赖

- M2 不重复定义账号；使用 M1 的学生、教师、管理员。
- 学生：本校、专业在课程专业范围内，可检索、加入、退出课程。
- 教师：本校，拥有一个或多个专业；可在本人专业范围内创建课程；加入老师组须与课程专业范围有交集；组内平权。
- 管理员：本校课程管理；不能创建课程。
- M2 引用 M1 的 school_id、major_id、class_id、account_id、role。

## 3. 核心概念

### 3.1 数据对象

| 对象 | 关键字段 | 说明 |
|---|---|---|
| 课程 | course_id、school_id、课程名称、created_by、状态、end_at | 教师创建；名称约定体现年级与课程类型，校内唯一；状态为启用 / 归档；end_at 为课程结束日期，供 M3 / M4 计算保留期 |
| 课程专业 | course_id、major_id | 课程与专业多对多；至少一个专业 |
| 课程教师 | course_id、account_id、状态（在组 / 已移出）、加入时间、移出时间 | 老师组；至少一名有效教师；组内权限相同；教师专业须与课程专业范围有交集；移出保留历史 |
| 课程学生 | course_id、student_account_id、加入方式、状态（在课 / 已退出 / 已移出）、加入时间、退出时间 | 课程成员是学生名单；退出 / 移出保留历史 |

### 3.2 关系

- 一门课程属于一所学校，可隶属多个专业，可挂多名教师、多名学生。
- 课程与专业为多对多；学生能否看到 / 加入课程，取决于其专业是否在课程专业范围内。
- 学生与课程、教师与课程均为多对多。
- 课程教师、课程学生关系采用软删除，保留加入 / 移出时间与状态；同一时间同一课程 / 成员只有一条有效关系。
- 课程是一次开课的容器，不跨届复用；同一门课下一届再开时新建课程。
- 班级不参与课程结构；M2 不持久化课程-班级关系，只读取班级名单用于批量加人；停用班级不可用于批量加人。
- M2 依赖 M1；M1 不依赖 M2。

## 4. 业务规则

1. 只有教师能创建课程；管理员不能创建课程。
2. 课程名称为自由文本，约定体现年级与课程类型，系统不做结构化拆分；课程名称在同一学校内唯一，同名课程需通过名称区分。
3. 课程可隶属多个专业，创建时至少选择一个专业；所选专业须为启用状态；课程专业范围创建后不可修改（默认）。
4. 课程属于一所学校；所属学校创建后不可修改。
5. 教师创建课程时，所选专业必须全部在本人专业范围内；其他教师加入老师组时，本人专业须与课程专业范围至少有一个交集。
6. 老师组至少保留一名有效教师；组内权限相同，任何成员可添加 / 移出同校教师；管理员可添加 / 移出成员；移出时标记失效并保留历史；添加教师时须校验其专业与课程专业范围有交集，管理员同样适用。
7. 学生只能检索本校、且专业在课程专业范围内的启用课程。
8. 学生自主加入 / 退出课程，无需教师审批；退出或被移出时标记失效并保留历史，重新加入生成新的有效关系（默认）。
9. 教师按班级批量拉人时，班级专业须在课程专业范围内；按账号 ID 拉人时，学生须同校且专业在课程专业范围内。
10. 管理员可编辑、归档 / 恢复本校课程、管理老师组和学生名单，但不能创建课程；管理员添加学生同样受课程专业范围约束，移出不受限（默认）。
11. 老师组可编辑课程名称和课程结束日期、管理学生名单；不能归档或删除课程（默认仅管理员可归档 / 恢复）。
12. 管理员归档课程时不删除老师 / 学生关系，历史保留；归档课程对学生不可见、不可加入（默认）。
13. 教师专业范围被管理员修改后，已有的课程老师组成员关系保留；新建课程、加入老师组按修改后的专业范围校验。
14. 课程教师、课程学生关系采用软删除，保留加入 / 移出时间与状态；同一时间同一课程 / 成员只有一条有效关系。
15. 同一门课下一届再开时新建课程记录，不复用原课程；不引入学期 / 开课批次实体。
16. 课程结束日期由教师组或管理员设置；M3 / M4 以 end_at 计算录像与报告的保留期，未设置时以归档时间计算。

## 5. 功能需求

### FR-M2-01 创建课程（教师，P0）

- 教师在本校创建课程，填写课程名称，选择一个或多个专业作为课程专业范围；所选专业必须全部在创建者本人的专业范围内。
- 同一门课下一届再开时新建课程，不复用原课程。
- 可选填写课程结束日期 `end_at`；未填写时按归档时间计算保留期（M3 / M4）。
- 建课教师自动成为老师组成员。
- 课程仅对本校、专业在课程专业范围内的学生可见、可加入。
- 异常：未选择专业、所选专业不属于本校、所选专业已停用、所选专业超出创建者本人专业范围、课程名称在本校已存在、创建者不是本校教师时阻止创建。

### FR-M2-02 课程专业范围（P0）

- 课程可隶属多个专业，至少一个。
- 课程专业范围在创建时确定，创建后不可修改（默认）。
- 学生可见性与教师拉人校验均以该范围为准。

### FR-M2-03 老师组管理（P0）

- 老师组至少保留一名有效教师。
- 组内权限相同，任何成员均可添加 / 移出同校教师，不设创建者特权。
- 移出教师时标记失效并保留历史记录，不物理删除。
- 添加教师时，须校验其专业与课程专业范围至少有一个交集；管理员添加时同样适用（默认）。
- 管理员可添加 / 移出本校课程的老师组成员，不受老师组限制。
- 异常：移出后没有有效教师时阻止操作；教师专业与课程专业范围无交集时拒绝加入。

### FR-M2-04 学生检索课程（P0）

- 学生只能检索本校、且专业在课程专业范围内的启用课程。
- 支持按课程名称、教师用户名检索（默认）。
- 列表展示课程名称、老师组、学生人数（默认）。
- 异常：跨校、专业不在课程范围内或课程已归档时不可见。

### FR-M2-05 学生加入 / 退出课程（P0）

- 学生自主加入，无需教师审批；同一课程同一时间只允许一条有效关系，重复加入拦截。
- 学生可退出课程（默认），退出时标记失效并保留历史，不物理删除。
- 被教师或管理员移出后，学生可重新加入（默认，不做黑名单）；重新加入生成新的有效关系，历史保留。
- 异常：课程不存在、课程已归档、跨校、专业不在课程范围内时拒绝加入。

### FR-M2-06 教师添加学生（P0）

- 按班级批量：只能选择处于启用状态、且专业在课程专业范围内的班级，班级内学生批量加入课程；已加入的跳过并反馈结果。
- 按账号 ID 单个：输入账号 ID，校验账号存在、身份为学生、同校且专业在课程专业范围内（默认）。
- 操作结果按成功 / 已存在 / 不存在 / 跨校 / 专业不符等分类反馈。

### FR-M2-07 课程成员管理（P0）

- 老师组可查看课程学生名单（用户名、账号 ID、班级等；用户名为真实姓名），默认展示有效成员，可查看历史成员。
- 老师组可将学生移出课程（默认）；管理员也可移出；移出时标记失效并保留历史。
- 老师组可编辑课程名称和课程结束日期（默认）；课程名称需校内唯一；所属学校、课程专业范围创建后不可修改（默认）。
- 老师组不能归档或删除课程（默认）。
- 课程物理删除本轮不做；管理员归档 / 恢复课程见 FR-M2-08。

### FR-M2-08 管理员课程管理（P0）

- 管理员可查看、编辑、归档 / 恢复本校所有课程；不物理删除课程。
- 管理员可添加 / 移出课程老师组成员、管理课程学生名单；添加教师时同样校验教师专业与课程专业范围有交集（默认）。
- 管理员添加学生与教师共用同一套校验：按班级批量时班级须启用且专业在课程范围内，按账号 ID 时学生专业须在课程范围内；移出学生不受此限制（默认）。
- 管理员不能创建课程。
- 归档课程需二次确认；归档不删除老师 / 学生关系，历史保留；归档课程对学生不可见、不可加入。
- 异常：管理员创建课程时拒绝。

### FR-M2-09 权限与可见性（P0）

- 学生：只能看到本校、专业范围包含其专业的课程；只能操作自己的课程关系。
- 教师：只能管理自己所在老师组的课程；创建课程所选专业须在本人专业范围内；加入老师组须与课程专业范围有交集；未加入老师组的课程不可管理。
- 管理员：可编辑、归档 / 恢复本校所有课程；不能创建课程；不能管理其他学校课程。
- 跨校访问一律拒绝。
- M2 使用 M1 签发的 token、role、school_id 做基础校验，课程级归属校验在 M2 内完成。

## 6. 主要流程

### 6.1 教师建课

1. 教师登录（M1）。
2. 创建课程，填写课程名称，选择本人专业范围内的专业；可选填写课程结束日期。
3. 按需添加同校、且专业与课程专业范围有交集的教师组成老师组。
4. 按班级批量或按账号 ID 单个加入学生。
5. 查看、维护课程学生名单。

### 6.2 学生选课

1. 学生登录（M1）。
2. 检索本校、专业范围包含其专业的课程。
3. 自主加入课程；可退出或重新加入；退出 / 移出保留历史，重新加入生成新的有效关系。

### 6.3 管理员管课

1. 管理员登录（M1）。
2. 查看本校课程。
3. 编辑 / 归档 / 恢复课程，管理老师组和学生名单。
4. 不能创建课程。

## 7. 权限矩阵

| 操作 | 学生 | 教师 | 管理员 |
|---|---|---|---|
| 创建课程 | — | 可（专业须在本人专业内） | 不可 |
| 编辑课程名称 | — | 所在老师组可 | 本校可 |
| 编辑课程结束日期 | — | 所在老师组可 | 本校可 |
| 归档 / 恢复课程 | — | 不可 | 本校可 |
| 管理老师组 | — | 所在老师组可* | 本校可* |
| 检索课程 | 本校 + 专业范围 | 本校 | 本校 |
| 加入 / 退出课程 | 可 | — | — |
| 按班级或账号 ID 添加学生 | — | 所在老师组可 | 本校可（专业须在课程范围内） |
| 移出课程学生 | — | 所在老师组可 | 本校可 |
| 跨校访问 | 不可 | 不可 | 不可 |

> * 添加教师时，教师专业须与课程专业范围至少有一个交集；添加学生时，班级 / 学生专业须在课程专业范围内；教师与管理员适用同一规则。

## 8. 异常与边界

- 未选择专业或专业不属于本校：阻止创建课程。
- 所选专业超出创建者本人专业范围：阻止创建课程。
- 老师组只剩一名有效教师时再移出：阻止操作。
- 教师专业与课程专业范围无交集：拒绝加入老师组。
- 重复加入课程：拦截并提示已有有效关系。
- 学生专业不在课程范围内：拒绝加入并说明原因。
- 按班级批量加入时选择了专业不在课程范围内的班级：拒绝该班级并提示（默认）。
- 班级批量加入时部分学生已存在：跳过已存在的，返回成功与跳过清单。
- 管理员添加专业不在课程范围内的学生 / 班级：拒绝（默认）。
- 教师管理非自己老师组的课程：拒绝（403）。
- 管理员创建课程：拒绝（403）。
- 教师归档课程：拒绝（403，默认）。
- 归档课程：不删除老师 / 学生关系，历史保留；归档后学生不可见、不可加入（默认）。
- 对已归档课程加入、拉人或选课：拒绝。
- 课程成员退出 / 移出：标记失效并保留历史，不物理删除。
- 空课程、空学生名单：允许存在。

## 9. 验收要点

1. 教师可在本人专业范围内创建课程并选择多个专业；对应专业的学生能检索到并加入。
2. 老师组内任意教师都能互相拉人 / 移出教师；被拉入的教师须与课程专业范围有交集；管理员也能添加 / 移出老师组成员。
3. 管理员不能创建课程，但能编辑 / 归档 / 恢复本校课程、管理老师组和学生名单；添加学生时同样受课程专业范围约束。
4. 学生只能检索到本校、专业范围包含其专业的启用课程，可加入、退出、重新加入；退出 / 移出保留历史。
5. 教师按班级批量或按账号 ID 拉人时，跨校 / 专业不符被拒绝。
6. 教师不能管理自己未加入老师组的课程。
7. 跨校访问一律拒绝。
8. 教师不能创建本人专业范围外的课程，也不能加入与自己专业无交集的课程老师组。
9. 停用专业不能用于新建课程，停用班级不能用于批量加人。
10. 管理员修改教师专业范围后，已有老师组关系保留；新建课程和新加入按修改后的范围校验。
11. 课程、老师组、课程学生关系采用软删除，历史可追溯；归档课程不物理删除。
12. 归档课程后学生不可见、不可加入；管理员可恢复。
13. 同一门课下一届再开时通过新建课程解决，不复用原课程。
14. 教师组或管理员可设置课程结束日期；M3 / M4 以此计算录像和报告的保留期。
15. 课程名称在同一学校内唯一；重复名称无法创建或改名。
