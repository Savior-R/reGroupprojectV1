一）、核心功能需求（按使用流程）
1）身份与课程管理
师范生 / 教师身份登录，绑定专业、年级、课程（语文 / 数学 / 英语 / 思政 / 幼教等）
班级管理、小组训练、教师批阅与点评
试讲任务发布：课时、学段、教材版本、评分标准

> **本轮细化范围**：拆分为 [M1 账号管理与身份认证](M1-账号管理与身份认证.md) 和 [M2 课程操作与管理](M2-课程操作与管理.md)；小组训练、教师批阅与点评、试讲任务发布顺延。

2）AI 虚拟课堂（核心体验）
虚拟学生：可设定人数、课堂行为（专注、走神、举手、提问、小声说话）
虚拟课堂环境：黑板 / PPT / 板书区、讲台视角、课堂氛围音
支持实时互动： 
虚拟学生举手提问
虚拟学生回答问题（对 / 错 / 不完整）
课堂纪律模拟（吵闹、走神）
支持三种模式：自由试讲、情景模拟、结构化面试
3）试讲录制与直播
全程音视频录制：人像 + 屏幕 + 板书 + 声音
支持本地保存 / 云端存档 / 回看复盘
支持教师在线观摩、实时指导
4）AI 多维度教学能力评测（核心价值）
(1)教学内容
知识点准确性、逻辑清晰度、重难点把握
语言规范性、术语正确性、讲解完整度
(2)教学表达
普通话标准度、语速、停顿、音量、流畅度
口头禅检测（“嗯 / 那个 / 就是”）
(3)教姿教态
站姿、手势、眼神、面部表情
走动合理性、与 “学生” 互动感
(4)课堂互动与控场
提问设计、引导能力、反馈评价
课堂纪律处理、应急话术
鼓励性语言、课堂节奏把控
(5)板书 / PPT 呈现
板书结构、字迹工整度（可选 OCR）
PPT 使用合理性、时间分配
(6)时间管理
导入 — 新授 — 练习 — 小结 — 作业 各环节时长
超时 / 提前结束提醒
5）即时反馈与改进建议
AI 生成评测报告：分数 + 维度雷达图
问题定位：哪里讲太快、哪里不清晰、哪里互动不足
提供优化话术、示范片段、逐句建议

> 第 2、3 点合并细化为 [M3 虚拟课堂与录制](M3-虚拟课堂与录制.md)；第 4、5 点合并细化为 [M4 AI 评测与反馈](M4-AI评测与反馈.md)。

6）教材与题库资源
按学段 + 学科 + 教材提供试讲题目
教案模板、板书模板、优秀试讲范例
教师资格证面试真题 / 结构化题库

> 第 6 点本轮只做结构化面试题库，细化为 [M5 结构化面试题库](M5-结构化面试题库.md)；教材、教案、板书模板、优秀范例后续补充。

7）训练模式（阶梯提升）
入门：跟读训练、语音语调纠正
进阶：无提示完整试讲
高阶：突发情景模拟（学生质疑、课堂混乱、设备故障）
模拟考核：全真计时 + 考官评分标准

> 第 7 点细化为 [M6 训练模式](M6-训练模式.md)：本轮只做进阶、模拟考核；高阶、入门后续。

8）教师 / 管理员后台
查看班级试讲数据、平均分、薄弱项
批量批阅、文字 / 语音点评、打分
导出成绩、训练报告、排行榜
自定义评分细则、发布作业

> 第 8 点细化为 [M7 教师评测与数据统计](M7-教师评测与数据统计.md)：教师评分、AI / 教师权重、统计、排行榜与导出；管理员可管理 M1 / M2 元数据与 M5 题库，不参与 M3 / M4 / M6 / M7 评测业务。

9）达标与认证
技能达标证书（教学表达 / 互动 / 控场 / 时间）
薄弱项专项训练推送
历史进步曲线对比

> 第 9 点 M8 达标与认证暂缓，不纳入当前范围；后续再细化。
