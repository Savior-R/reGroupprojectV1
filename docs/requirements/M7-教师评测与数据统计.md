## 1. 范围

### 1.1 本轮实现

- 教师按课程 / 任务查看学生提交件、AI 评分与评测状态
- 每个任务由课程老师组设置 AI 分 / 教师分权重，默认 70 / 30；首次评分后锁定
- 教师按五维（结构化面试三维）打分，或直接给总分
- 教师文字评语、表格内批量保存
- 最终总分与最终维度分合成
- 任务 / 班级平均分、薄弱项、排行榜、完成情况
- CSV 导出
- 学生只读查看本人最终分、AI 分、教师分与评语
- 只读消费 M3 / M4，演示时可用种子数据独立运行

### 1.2 本轮不做

- 管理员评测业务；管理员只做 M1 / M2 的元数据管理
- 语音点评、自定义评分细则、发布作业
- 训练记录（M6 训练结果仅学生本人可见，教师不可见）
- 学生申诉、复核、仲裁
- 历史进步曲线、达标认证（M8 暂缓）
- AI 自动生成评语、自动批阅
- 修改或重跑 M4 的 AI 评测结果
- 跨校统计、跨课程排行榜
- 课程 / 班级 / 账号维护（M1 / M2）
- Excel / PDF 导出（本轮只做 CSV）

## 2. 角色与依赖

| 角色 | 说明 |
|---|---|
| 学生 | 只读查看本人最终分、AI 分、教师分与评语；不能查看他人 |
| 教师 | 课程老师组；设置任务权重与打分模式、录入评分与评语、查看统计、导出 |
| 管理员 | 不进入 M7；学校 / 专业 / 班级 / 账号 / 课程元数据在 M1 / M2 |
| 系统 | 只读 M3 / M4；计算最终分与统计；生成 CSV；不写回 M3 / M4 |

- M1 提供账号、学校、班级；M2 提供课程、课程老师组、学生有效关系、课程归档状态与 `end_at`。
- M3 提供任务、任务分配快照、提交件、提交时班级快照、任务配置快照与维度权重。
- M4 提供 AI 评测、维度分、总分、评测状态与报告链接。
- M6 训练记录不进入 M7；教师不能查看训练结果。
- M7 不修改 M3 / M4 的原始数据；通过只读数据适配层或数据库视图读取；演示环境可使用种子数据。
- M8 达标与认证可读取 M7 的 `final_total`、最终维度分与时间序列。

## 3. 核心概念

### 3.1 数据对象

| 对象 | 关键字段 | 说明 |
|---|---|---|
| 任务评分配置 TaskGradingConfig | config_id、task_id、course_id、ai_weight、teacher_weight、scoring_mode、config_version、locked_at、updated_by、updated_at | 每个任务一条有效配置；权重和为 100%；`scoring_mode` 为 dimension / total；首次教师评分后锁定 |
| 教师评分 TeacherScore | teacher_score_id、submission_id、task_id、course_id、student_account_id、class_id_snapshot、scoring_mode、dimension_scores、teacher_total、comment、version、graded_by、graded_at、updated_at | 每个提交件最多一条有效评分；课程老师组共享；保存时校验 `version`，冲突返回 409 |
| 最终分 FinalScore | submission_id、ai_evaluation_id、teacher_score_id、ai_total、teacher_total、final_total、final_dimensions、status、class_id_snapshot、config_version、computed_at | 派生结果；可实时计算或缓存，不替代 M4 评测；班级快照用于统计 |
| 成绩状态 | not_submitted、pending_ai、pending_teacher、completed、ai_partial、ai_failed | 用于名单、统计与导出；只有 completed 进入正式统计 |
| 班级快照 | class_id_snapshot | 优先取 M3 提交时快照；缺失时依次取教师评分 / 最终分快照；用于历史统计稳定 |

### 3.2 关系

- 一个任务对应一条有效任务评分配置；配置变更时 `config_version` 递增。
- 一个提交件对应最多一条有效教师评分；同一提交件被课程老师组多名教师编辑时，更新同一条记录，保留最后编辑人与更新时间。
- 一个提交件对应一条 M4 AI 评测；以 `source_type = task_submission`、`source_id = submission_id` 关联。
- 最终分由 AI 总分、教师总分与任务评分配置合成；配置、AI 评测或教师评分变化后重新计算。
- 任务分配快照决定评分名单；未提交的学生只显示状态，不进入评分与统计。
- M7 只处理课程任务提交件，不处理 M6 训练记录。

## 4. 业务规则

1. M7 只处理 M3 的课程任务提交件（`session_type = task` 且已提交）；训练记录、未提交会话、临时录像不进入 M7。
2. 每个任务由课程老师组设置 AI 分 / 教师分权重，默认 70 / 30；两项取值 0—100，和为 100；任一教师可修改，记录 `updated_by`、`updated_at`，`config_version` 递增。
3. 打分模式与权重按任务设置：`dimension`（维度分，默认）或 `total`（直接总分）；权重默认 70 / 30。首次保存教师评分后同时锁定模式和权重（写入 `locked_at`）；如需修改，必须先清空该任务已保存的教师评分并二次确认。
4. 维度集合按任务模式决定：自由试讲 / 情景模拟为教学内容、教学表达、课堂互动与控场、板书 / PPT、时间管理五维；结构化面试为教学内容、教学表达、时间管理三维。
5. 教师维度打分取 0—100，保留一位小数；教师总分按 M3 配置快照中的维度权重合成（结构化面试为 40 / 30 / 30）；教师直接总分同样取 0—100，保留一位小数。
6. 最终总分 = AI 总分 × `ai_weight` / 100 + 教师总分 × `teacher_weight` / 100，保留一位小数；权重为 0 的一项不要求存在对应分数。
7. 最终维度分：教师提供了维度分时，按同一权重合成 AI 维度分与教师维度分；教师只给总分时，最终维度分直接使用 AI 维度分；AI 维度缺失而教师维度存在时使用教师维度分；两边都缺失时为空。若 `ai_weight = 0` 且教师只给总分，最终维度分为空，仅统计总分。
8. 最终分状态由权重所需项决定：`ai_weight > 0` 时 AI 必须完成，`teacher_weight > 0` 时教师评分必须存在；所需项未完成 → `pending_ai` / `pending_teacher`；所需项齐全 → `completed`；当 `ai_weight > 0` 且 AI 为 `partial / failed` → `ai_partial / ai_failed`；`ai_weight = 0` 时忽略 AI 状态。
9. 只有 `completed` 的提交件进入平均分、薄弱项、排行榜和正式导出；`pending_*` 与 `ai_partial` / `ai_failed` 单独计数，不计入正式统计。
10. 薄弱项按最终维度平均分从低到高排序，默认展示最低 2 项；平均分低于 60 分标记为薄弱；有效样本少于 3 人时标注「样本不足」。
11. 排行榜按最终总分降序；同分依次比较教师总分、AI 总分、账号 ID；只统计 `completed`，支持按任务和班级筛选。
12. 班级统计优先使用 M3 `Submission.class_id_snapshot`；缺失时依次使用 `TeacherScore.class_id_snapshot`、`FinalScore.class_id_snapshot`。学生之后转班不改变历史统计；无班级时归入「未分班」。
13. 课程老师组内所有有效教师共享同一份教师评分；任何成员可创建 / 修改；保存时校验 `version`，版本不一致返回 409，不静默覆盖；本轮保留 `graded_by`、`updated_at`，不做逐次修订历史。
14. 任务关闭后仍可评分；课程归档后 M7 转为只读，不能修改权重、模式或评分，但仍可查看统计和导出。
15. 学生退课或被移出课程后，已提交的试讲仍保留；M7 保留其历史评分与统计，班级快照不变；名单中标注「已退课 / 已移出」。
16. `ai_weight > 0` 且 AI 评测 `pending / running` 时，教师可以先评分，最终分待 AI 完成后自动计算；`ai_weight > 0` 且 `partial / failed` 时保留教师评分，但不计算最终分，也不进入统计；`ai_weight = 0` 时忽略 AI 状态。
17. 未配置任务评分配置时，系统按默认 70 / 30、`dimension` 模式处理；首次访问时生成默认配置，教师可修改。
18. 未锁定前修改权重或模式，该任务已计算的最终分实时重算；首次教师评分后锁定，需清空该任务教师评分才能修改。本轮不做配置变更历史，只保留当前版本、最后修改人与 `locked_at`。
19. 评分与评语范围：分数 0—100，保留一位小数；评语为纯文本，最多 1000 字；本轮不支持语音、附件或富文本。
20. 导出为 CSV（UTF-8 BOM），按当前筛选条件生成；不落盘保存导出文件，直接下载。
21. 学生只能查看自己的最终分、AI 分、教师分与评语；不能查看他人；管理员不可查看；课程老师组可查看本课程。
22. 保留期与 M3 / M4 一致：教师评分与最终分随提交件保留至课程结束 + 1 年；课程未设置 `end_at` 时以归档时间计算；到期后随 M3 / M4 数据清理。
23. 跨校、跨课程、非老师组访问一律拒绝；M7 不提供管理员视角。
24. M7 不修改 M4 的评测结果；最终分是独立合成结果，报告中应明确区分「AI 分」「教师分」「最终分」。

## 5. 功能需求

### FR-M7-01 任务评分配置（P0）

- 课程老师组可为任务设置 `ai_weight`、`teacher_weight`，默认 70 / 30；两项 0—100，和为 100。
- 设置打分模式：`dimension`（默认）或 `total`；结构化面试自动使用三维。
- 首次保存教师评分后锁定打分模式与权重（写入 `locked_at`）；修改需先清空该任务教师评分并二次确认，清空后解除锁定。
- 清空评分后最终分缓存失效并按新配置重算；未评分学生保持 `pending_teacher`。
- 配置修改递增 `config_version`，记录 `updated_by`、`updated_at`；未锁定时修改后重算最终分。
- 异常：非课程老师组、课程已归档、权重和不为 100、取值越界、已有评分时修改权重或切换模式，阻止或要求确认。

### FR-M7-02 评分名单与状态（P0）

- 教师按课程选择任务，查看发布时任务分配快照中的学生名单。
- 展示：学生、班级快照 / 当前班级、提交状态、AI 评测状态、教师评分状态、最终分状态。
- 支持按班级、状态、姓名 / 账号 ID 筛选。
- 未提交、进行中的学生只显示状态，不能评分。
- 异常：草稿任务无名单；课程归档只读；非老师组拒绝。

### FR-M7-03 教师评分（P0）

- `dimension` 模式：录入各维度分，系统按任务维度权重计算教师总分。
- `total` 模式：直接录入教师总分，不录维度分。
- 支持表格内逐行保存与批量保存；批量保存按行返回成功 / 失败原因，允许部分成功。
- 评分保存时写入 `class_id_snapshot`、`graded_by`、`graded_at`；再次修改更新 `updated_at` 并递增 `version`。
- 修改已有评分时校验 `version`；版本不一致返回 409（批量保存该行标记冲突），不覆盖他人修改。
- 教师可在 AI 评测完成前先评分；AI 权重大于 0 时最终分状态保持 `pending_ai`。
- 异常：分数越界、维度与任务模式不符、评语超长、提交件不存在 / 未提交、课程已归档、非老师组，拒绝该行。

### FR-M7-04 最终分合成（P0）

- 按第 4 章公式计算最终总分与最终维度分；保留一位小数。
- 状态：`pending_ai`、`pending_teacher`、`completed`、`ai_partial`、`ai_failed`；状态只由权重大于 0 的所需项决定。
- 权重为 0 的项不要求对应分数；`ai_weight = 0` 时忽略 AI 状态，`teacher_weight = 0` 时忽略教师评分。
- 配置、AI 评测或教师评分变化后自动重算；同一提交件的 `final_total` 幂等。
- 异常：`ai_weight > 0` 且 AI `partial / failed` 时不计算最终分；所需项缺失时返回对应 pending 状态；不修改 M4 数据。

### FR-M7-05 统计、薄弱项与排行榜（P0）

- 统计维度：任务、班级、课程；支持按任务和班级筛选。
- 展示：任务分配人数、提交人数、已完成人数、待 AI / 待教师人数、平均最终分。
- 维度统计：各最终维度平均分、有效样本数、最低 2 项薄弱项；低于 60 分标红。
- 排行榜：按最终总分降序，展示名次、学生、班级、AI 分、教师分、最终分；同分按规则排序。
- 只统计 `completed`；`pending_*`、`ai_partial`、`ai_failed` 单独计数，不进入平均分和排行榜。
- 班级使用 M3 提交时班级快照；缺失时回退到教师评分 / 最终分快照；有效样本少于 3 人标注「样本不足」。
- 异常：无提交 / 无完成数据时展示空态；课程归档只读；非老师组拒绝。

### FR-M7-06 导出（P0）

- 按当前课程、任务、班级、状态筛选导出 CSV；UTF-8 BOM，便于 Excel 打开。
- 字段：任务、课程、班级、学生姓名、账号 ID、提交时间、AI 总分、教师总分、最终总分、各维度分、教师评语、状态、评分教师、评分时间。
- 课程归档后仍可导出；管理员不可导出。
- 异常：空结果导出表头；超过 10000 行时提示缩小筛选范围（默认）；非老师组拒绝。

### FR-M7-07 学生结果查看（P0）

- 学生只能查看自己的最终分、AI 分、教师分、最终维度分与评语。
- 状态未完成时显示「待 AI 评测 / 待教师评分 / AI 评测不完整」，不展示半成品最终分。
- 本轮不做申诉、复核、重新评分申请。
- 异常：查看他人成绩、管理员访问、跨校访问，拒绝。

### FR-M7-08 权限与边界（P0）

- 教师：仅本课程老师组有效成员；只能操作本课程任务；课程归档后只读。
- 学生：仅本人成绩；不能查看他人或班级聚合。
- 管理员：不可访问 M7 的任何评分、统计或导出接口。
- 训练记录（M6）：教师不可见；M7 不展示、不统计。
- 跨校、跨课程、非老师组：拒绝。

### FR-M7-09 只读集成与演示数据（P0）

- 通过只读适配层 / 视图读取 M3 的 task、task_assignment、submission（含 `class_id_snapshot`）、config_snapshot，以及 M4 的 evaluation、dimension_score、status。
- M7 不写回 M3 / M4；所有最终分与统计在 M7 侧计算。
- 提供种子数据与演示模式：学校、教师、学生、课程、任务、提交件、AI 评测、教师评分均可预置，不要求先跑通 M3 / M4。
- 演示模式与生产模式使用同一套接口与计算逻辑，仅数据来源不同；种子数据不得进入生产环境。
- 异常：M3 / M4 数据缺失、ID 不一致、评测状态异常时，展示明确错误，不生成伪造分数。

### FR-M7-10 保留、归档与清理（P0）

- 教师评分与最终分随提交件保留至课程结束 + 1 年；未设置 `end_at` 时以归档时间计算。
- 课程归档后：禁止修改权重、模式和评分；允许查看统计与导出。
- 任务关闭后：允许继续评分，直到课程归档或保留期结束。
- 到期后由统一清理任务按 `submission_id` 级联删除教师评分与最终分，并与 M3 / M4 的录像、报告同期清理；清理后接口返回数据不存在。
- 异常：过期数据、已归档写入、课程结束日期缺失，按上述规则处理。

## 6. 主要流程

### 6.1 教师配置与评分

1. 教师登录，进入本课程任务。
2. 设置任务 AI / 教师权重（默认 70 / 30）与打分模式。
3. 查看任务分配名单与提交状态。
4. 在表格中按维度或总分录入教师评分与评语，逐行或批量保存。
5. 系统按权重合成最终分；AI 权重 > 0 且待 AI 完成时显示 `pending_ai`。
6. 查看任务 / 班级平均分、薄弱项、排行榜。
7. 按需导出 CSV。

### 6.2 批量评分

1. 选择任务与班级，筛选待评分学生。
2. 切换 `dimension` 或 `total` 模式（任务级）。
3. 表格内录入分数与评语，批量保存。
4. 系统逐行校验并返回失败原因；成功行立即参与最终分计算。

### 6.3 学生查看结果（P0）

1. 学生进入本人任务结果页。
2. 查看 AI 分、教师分、最终分、维度分与评语。
3. 未完成时显示状态，不展示半成品最终分。

### 6.4 独立演示

1. 启动演示数据：预置学校、教师、学生、课程、任务、提交件与 AI 评测。
2. 教师登录，配置权重、评分、查看统计、导出。
3. 不要求启动 M3 的课堂录制或 M4 的评测 worker；M7 读取种子数据即可完成演示。

## 7. 权限矩阵

## 8. 异常与边界

- 非课程老师组、跨课程、跨校访问：403。
- 管理员访问评分、统计、导出：403。
- 课程已归档：权重、模式、评分写入拒绝；查看与导出允许。
- 任务关闭：允许继续评分；未提交学生不能评分。
- 权重和不为 100、取值越界：阻止保存配置。
- 已有教师评分时切换打分模式：阻止，需先清空并确认。
- `ai_weight > 0` 且 AI 评测 `pending / running`：最终分 `pending_ai`，教师可先评分。
- AI 评测 `partial / failed` 且 `ai_weight > 0`：保留教师评分，最终分标记 `ai_partial / ai_failed`，不进入统计。
- `teacher_weight > 0` 且教师评分缺失：最终分 `pending_teacher`。
- 权重为 0 的项：不要求对应分数。
- 分数越界、维度不符、评语超长：拒绝该行并返回原因。
- 批量保存部分失败：成功行生效，失败行返回原因；不整批回滚（默认）。
- 同一提交件多名教师同时编辑：保存时校验 `version`；版本不一致返回 409（批量保存该行标记冲突），不静默覆盖。
- 学生转班：历史统计使用 `class_id_snapshot`，不回写。
- 学生退课 / 被移出：保留历史评分；名单标注状态。
- 课程结束日期缺失：以归档时间计算保留期。
- M3 / M4 数据缺失或 ID 不一致：不生成最终分，提示数据异常。
- 训练记录：不出现在 M7 名单、统计或导出中。

## 9. 验收要点

1. 教师可为任务设置 AI / 教师权重，默认 70 / 30；权重和不为 100 时无法保存。
2. 教师可按五维（结构化面试三维）打分并自动合成教师总分，也可直接录入总分。
3. 最终总分按权重合成；AI 分、教师分、最终分在界面上明确区分。
4. AI 权重大于 0 且未完成时教师可先评分，状态为 `pending_ai`；教师权重大于 0 且未评分时为 `pending_teacher`。
5. `completed` 提交件才进入平均分、薄弱项、排行榜；`ai_weight > 0` 且 `partial / failed` 的提交件不计入正式统计。
6. 班级统计优先使用 M3 提交时 `class_id_snapshot`；学生转班后历史统计不变。
7. 薄弱项按最终维度平均分排序，低于 60 分标红，样本少于 3 人标注样本不足。
8. 排行榜按最终总分降序，同分按教师分、AI 分、账号 ID 排序。
9. CSV 导出字段完整、UTF-8 BOM 可用；管理员无法导出。
10. 学生只能查看本人结果；管理员与训练记录均不可见。
11. 课程归档后 M7 只读，统计与导出仍可用。
12. 演示模式不启动 M3 / M4 也能完成配置、评分、统计与导出。
13. 多名教师同时修改同一评分时，版本冲突被拦截并提示刷新；教师评分不会静默覆盖。
